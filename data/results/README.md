# 結果パック

1 実行 = 1 ファイル(`<run_key>.sqlite`)。中身は統合 DB と同じスキーマで、その実行の runs / paths / jobs / equity / trades /
case_runs / case_defs だけを持つ。相場パターン(ローソク足・イベント)は `data/patterns/<data_key>.sqlite` に 1 つずつ。

- コミットするのはパックだけ。統合 DB(`data/fxsim.sqlite`)はコミットしない
- 統合 DB はパックから作る: `python -m fxsim db build`(作り直すなら `--fresh`)。既定の DB を開くコマンドは、
  まだ取り込んでいないパックを自動で取り込む
- 既定の DB への実験(demo 以外)は、終わったら自動でパックに書き出される。手で書き出すなら `python -m fxsim db export <run>`
- 実行を指すときは run_key を使う(`python -m fxsim report E007-2026...`、前方一致も可)。統合 DB の番号は、
  取り込んだ順(作成時刻の順)で振るので、環境やパックの集まり方で変わる
- パックは一度書いたら変えない。`compact` で資産曲線を間引いたときだけ書き直す
