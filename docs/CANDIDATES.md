# 戦略の候補

検証の状態ごとの、戦略の候補の一覧。投資の知見は `docs/INSIGHTS.md`、市場モデル・エンジンの課題は `docs/ROADMAP.md`。外の手法・AI トレード・日本と海外の違い・売り文句の調査は `docs/TRADING_LANDSCAPE.md`。

判定の基準は `fxsim verify`(E002): 30 年の実データ・並べ替えた別の歴史・偽薬・完全ランダムで、方向だけでたらめ版と対にして回す。
C1 利益(並べ替えで中央値 > 0・プラス ≥ 60%・t ≥ 2、かつ実データ > 0)/ C2 方向でたらめ版より上 / C3 偽薬より上 / C4 年ごとの安定性 /
C5 値動きの優位性(ドリフトを抜いた並べ替えで、スワップを除いた損益が C1 と同じ基準。2026-11-10 に追加、E011)。
全部 → 合格、C1・C2・C5 → 条件付き、それ以外 → 不合格。C5 を足した後、全 44 本は不合格(`fxsim verify --all --rejudge`)。

## 条件付きで追う候補
| 候補 | 何を確かめれば判定が変わるか | 必要な開発 |
|---|---|---|
| B008 キャリー + 移動平均 | 実際の金利でもスワップの分が残るか。スワップの上乗せ(ブローカー)で消えないか。ほかの通貨ペアでも同じか | 金利表の差し替え、複数の通貨ペア(`docs/ROADMAP.md`) |
| トレンド 63 日(basket_trend)・勾配ブースティング(xs_gbdt) | スワップの上乗せが小さい口座(fair、年率 0.25%)で verify を通るか。素の損益はドリフトを抜いた並べ替えでも残る(t 2.8・3.95、E010) | 動作ケースのブローカー違い(B019・B020) |

carry_trade(移動平均なし)と buy_and_hold も、勝ちの中身は同じ(円安と金利差)。E008 で malicious ブローカーでも総合がプラスなのはこの 3 本だけ。
値動きの優位性ではなく、「金利の高い通貨を持つ報酬」と「この期間の円安」なので、判定は金利と期間に強く依存する。

## まだ検証していない案
| 案 | 狙い | 根拠・注意 |
|---|---|---|
| B014・B015 を fair ブローカーで verify | スワップの上乗せ(壁 2)を外したときに通るか | 先に判定の穴(ROADMAP の高 2 件)を直す。直さないと金利の高い通貨を持つ戦略がまた誤って通る(E012) |
| 日中で素の損益がプラスの型を日足で(donchian_breakout・heikin_ashi・macd_cross) | 費用(壁 1)を外す | 素の損益は偽薬でも同じだけ残るので、日中の足の作り方の穴の疑いが先(E012) |
| 損切りの有無と幅の比較 | 損切りが期待値ではなく、最大 DD と破綻の割合をどれだけ減らすか | 癖の無い相場では損切りの期待値は 0(E007)。保険としての価値を数字にする |
| 時間を絞った版(T004 の型) | 優位性ではなく費用と危険を減らす使い方 | 東京時間だけのボリンジャーは負けが小さい(5 年で −3〜−11 万)が、素の損益はほぼ 0 |
| 群衆の構成 w を推定する戦略 | 最近どちらの型(順張り / 逆張り)が負けているかを見て切り替える | malicious の悪意の仕組み(M003)を逆手に取れるか。市場モデルの研究として正当(docs/MARKET_MALICE.md) |
| 五十日の仲値(gotobi)を実データで | 本物の時刻の癖 | 合成の相場には入れていないので、勝てないのが正しい(E006 / E008)。実データの 1 分足が要る |
| 賭け方を日足・1 日 1 回で | 費用を小さくしたときの分布の形と破綻までの年数 | 期待値は変わらない(E006)。破綻の割合・`ruin_years` を比べる |

## 候補にしないもの(これまでの評価で結論が出ている)
| 型 | 理由 | 記録 |
|---|---|---|
| 1 時間足以下の売買(EMA 交差・ブレイクアウト・逆張り・オシレーター・スキャルピング・ロンドンブレイク・ピボット) | 素の優位性が無く、費用(年 230〜650 pip、スキャルピングは口座がほぼ 0)で負ける。E006 の逆張りの勝ちは市場モデルの穴だった | E005、E007、E008、R008、M006 |
| テクニカルの順張り(MACD・一目・ADX・パーフェクトオーダー・平均足・カルマン) | 4 時間足でも全市場でほぼマイナス | E006、E008 |
| 賭け方(マーチンゲール・パーリー・ダランベール・フィボナッチ・ラブシェール・オスカーズ・グラインド・ケリー・ナンピン) | 期待値は変わらず、fair でも 91〜100% のパターンが破綻 | E006、E008 |
| 長期の平均回帰(long_term_value)・ボラ・ターゲット・タートル | 実データと並べ替えで結論が逆になる。総合はマイナス | E006、E008 |
| オンライン学習(online_logit)・局面の切り替え(regime_adaptive) | 回転が速く費用で負ける。malicious ブローカーで破綻 34〜100% | E006、E008 |
| 通貨の順位のモメンタム・名目のバリュー | 対円 7 ペアの 27 年で素の損益がマイナス / ほぼ 0 | S033、S034、E010 |
| リピート系(買い・売り) | 値幅を取る仕組みに優位性は無く(偽薬で素の損益 0)、勝ち負けは期間の向きと金利差で決まる。売りは円安で破綻 | S037 |
