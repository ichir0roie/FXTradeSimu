# 調査結果のまとめ(2026-11-13 時点)

このリポジトリで FX の売買の方法を検証してきた結果を、1 本にまとめたもの。細かい数字と手順は、各節の末尾に挙げた提案書
(`docs/proposals/`)と、知見の一覧(`docs/INSIGHTS.md`)にある。

> 投資の助言ではない。過去のデータとシミュレーションでの結果で、将来の成績を約束しない。

## 結論

1. **個人の口座で、値動きを読んで勝てる単純な規則は見つからなかった。** テクニカル指標・時間帯・指標発表・AI(LLM を含む)など、
   300 を超える型を試した。プラスに見えたものの多くは、検証の甘さ・市場モデルの作り方の癖・1 本の歴史への当てはめだった
2. **長く残ったのは、スワップ(金利差)を受け取る向きに、流れが出た数週間だけ乗る型(B049 系)。** 30 年・10 ペアの厳しい検証に
   合格した唯一の型で、年率は 6〜7%、最大ドローダウンは 18〜34%。稼ぎは金利差の環境しだいで、値動きを読む力ではない
3. **短い売買ほど、費用(スプレッドと滑り)で負ける。** 1 時間〜1 日の値動きで取れる偏りは、1 取引あたり 1 bp(0.01%)にも届かず、
   費用は一番安いペアでも 0.3〜0.6 bp、平均では 1 bp を超える。回数を増やすほど確実に負ける
4. **勝率の高さは当てにならない。** 「利確は小さく、負けは持ち続ける」形(ナンピン・マーチンゲール・逆指値なし)は、勝率 90% を
   超えても平均はマイナスで、まれな 1 回で口座の大半を失う
5. **本物の癖はいくつか見つかったが、小さすぎる。** 月末のロンドン 16 時のフィキシングの後のドル買い(年 0.1〜0.3%)、
   日時による時刻の癖(費用の 1/5〜1/10)

## どう判定したか

1 本のバックテストで勝つ型は、ありえた別の歴史では負けうる。だから次の物差しをそろえて判定した。

| 物差し | 中身 | 落とすもの |
|---|---|---|
| 方向でたらめ版との比較 | 同じ時期・同じ量・同じ出口で、向きだけを乱数にした版と対で回す | 向きを読む力の無い勝ち(円安・スワップに乗っただけ) |
| 並べ替えた相場(verify) | 実データを数か月の塊で並べ替えた別の歴史を 10 本、30 年 | 1 本の歴史への当てはめ |
| 偽薬・ランダムウォーク | 癖の無い相場で同じ勝ちが出ないか | 約定の決まりや市場モデルの作り物 |
| 実データのペア x 期間(pair-eval) | 主要 10 ペアを 4〜6 年ずつに切る | 1 ペア・1 時期だけの勝ち |
| 発見・確認・初見 | 型を選ぶ期間と、確かめる期間を分ける。さらに選ぶのに一度も使っていない古い期間・別のペアで確かめる | 試した数の多さによる偶然 |

判定は取引単位ではなく、パターン(相場 1 本)単位の t 値で行う。同じ相場の中の取引は独立ではないので、取引単位の統計は
有意さを大きく見せる。

## 分かったこと

### 1. 費用と回転

- 1 時間足の戦略(年 100〜300 回)は費用だけで年 230〜650 pip 削られる。スキャルピング(年 3,000 回)は、良心的な業者でも
  10 年で口座がほぼ 0(E006・E008)
- 費用が 1 取引の値動きに占める割合は、5 分で 31%、1 時間で 7〜9%、1 日で 2%、2〜10 日で 1.5% 前後。費用を越えうるのは
  1 日以上持つ型から(E021)
- 費用の見積もりはほぼ本当だった。デモ口座の実際の約定(USDJPY)で払ったスプレッドは 0.48 pip(足の記録 0.41 pip)、
  注文から約定までの滑りは 0。ただし費用は bp でペアごとに 10 倍以上違い(EURJPY・USDJPY 0.2〜0.3 bp、NZD・CHF のクロス 3〜6 bp)、
  2010〜2015 年は今の 2〜5 倍広かった(E068)
- 安いペアに絞って滑りを 0 にしても、日中の型は有意に勝たない。負けの原因は費用だけでなく、取れる偏りそのものが小さいこと(E068)
- ロールオーバーの時間(日本時間 6〜7 時)はスプレッドが 6 倍以上に開く。日足の戦略をこの時間に約定させると 1 取引 7〜11 pip
  払う(E017)。この時間の「勝ち」は、足の記録の作り物であることが多い(E015)

### 2. テクニカルの規則

- 31 の手法(EMA 交差・RSI・ボリンジャー・一目・MACD・タートル・パラボリック SAR など)と、日足の 184 型を発見(1996〜2013)と
  確認(2014〜2026)に分けて測り直した。両方の期間で有意な型は無い。2014 年前後で性質が入れ替わり、順張りは前半だけ、逆張りは
  後半だけプラス(E006・E008・E048)
- 手法の実装を理論どおりにしても(RSI の戻り待ち・三役好転・グランビルなど)結果は変わらない。負けの原因は使い方ではない(E048)
- 日中の型(1 分〜4 時間足)は、局面を絞っても、指値で入っても、初見のデータでは費用を越えない(E013・E015・E020・E049〜E055)
- 直近の値動きの帯の外に両側の指値を置く型(利用者の案)は、刺さった後に値が走るので負ける(逆選択)。平均線・ボリンジャー・
  ケルトナー・ドンチアンを基準にしても同じ(E060)

### 3. 時期で勝ち負けが入れ替わる

- 週足の逆張り(平均から大きく離れたら逆に張り、平均で利確)は、2010〜2026 年なら 1 取引 +89〜95 bp(t 3.3〜3.5)と強く見えた。
  ところが選ぶのに使っていない 1994〜2010 年では 288 通り中 283 がマイナスで、裏返した順張りが勝った(E060)
- 負けは大きな流れの年にまとめて来る(2008 年の金融危機、2013 年のアベノミクスの円安、2003 年のドル安)
- 1 本の時期を発見と確認に分けるだけでは、時期の性質を見抜けない。選ぶのに一度も使っていない時期で確かめるまで採らない

### 4. 賭け方・ナンピン・逆指値なし

- マーチンゲール・ナンピン・ケリーなど 9 通りの賭け方は、期待値を変えず分布の形だけを変える。良心的な業者でも 91〜100% の
  パターンが破綻した(E006・E008)
- 指標発表で片側に入り、跳ねたら利確、逆指値なしで負けは落ち着いてから閉じる型(利用者の案)は、雇用統計・新規失業保険申請件数・
  発表の種類を問わない急変のどれでも負けた。研究の約定でも、本物のエンジン(7 本)でも同じ(E062・E063・E067・S053)
  - 「落ち着いたら閉じる」で損を確定させているだけ。落ち着くのは元に戻ったからではなく、新しい水準で止まったから
  - 利確は +5〜22 bp で頭打ち、負けは青天井。負けの合計の 73〜100% を、下位 5% の取引が占める。最悪の 1 本はレバレッジ無しで −13%
  - 勝ち負けは発表の足がどちらに終わるかで決まり、その向きは当てられない(20 日の流れに合わせても当たり 53%)
- 裏返しても(損切りは小さく、勝ちは伸ばす)、費用は向きを逆にしても消えないので勝たない(E060・E062)

### 5. 時刻・暦の癖

- 時間帯・曜日の癖は実在するが、費用を越えない。日時の特徴だけで学ぶモデル(LightGBM)は、学習に使っていない年でも翌 1 時間の
  向きを当てる(10 ペアで t 4.95)が、取れるのは 1 取引 0.1〜0.4 bp で、費用込みはマイナス(E015・E064)
- 五十日の仲値の前の円売りは、2018 年より後だけ素で +1〜2 bp、費用込みで 0(E061)
- 月末のロンドン 16 時のフィキシングの後 1〜2 時間はドルが買い戻される。7 ペア中 6 本・17 年中 13 年でプラス、隣の日には無く、
  本物のエンジンでも方向でたらめ版との差が t 3.5。ただし年 12 回 x 1〜2 bp で、口座では年 0.1〜0.3%(E061・S052)

### 6. AI に判断させる

- LLM に過去の日付で売買を判断させると、LLM はその後の相場を学習で知っているので、成績は全部かさ上げされる。日付を隠しても
  文面から時期は分かる。過去のデータでは正しく測れない(E061)
- 知識の締め切り(2026 年 6 月)より後の 4 か月だけで、道具を持たない LLM に 10 ペアの毎日の向きを決めさせた。当たり 47.7%、
  費用込み 1 取引 −2.65 bp で、でたらめな向きと区別できない。LLM は締め切りの時点の見立て(ゆるいドル安・円安)を延ばし、
  実際にはドル高・円高に振れて負けた(E066)
- 学習するモデルも勝たない。オンライン学習は回転が速く費用で負け(E006・E008)、勾配ブースティング(月次の通貨の順位)は
  素の損益が残るが、試した数で割り引くと偶然と区別できない(E010)

### 7. スワップ(金利差)

- 金利の高い通貨を持つ型(キャリー)の勝ちの大部分はスワップ。値動きの損益はほぼ 0 か、高金利通貨の値下がりでマイナス(E010)
- 「スワップを受け取る向きだけ」に絞ると、日足の型はほとんど勝つが、方向でたらめ版も同じだけ勝つ。中身はキャリー(E018・E022)
- 効いたのは、金利差が大きく値の振れが静かなときに、流れが出た 2〜5 週間だけ乗ること。崩れ始めた相場に入らないので、
  1998・2008・2015・2020 年などの急変の時期に建玉を持っていなかった(E026〜E032)
- スワップの受け取りは業者の取り分で減り、受け取りの小さいペアでは消える(E027)

### 8. FX の外: 株価指数のレバレッジ

- FX の値動きには期待値が無いので、レバレッジは振れ幅を大きくするだけ。株価指数には期待値(株式リスクプレミアム)があり、
  適したレバレッジは借りる金利で決まる。指数 9%・ボラ 18% なら、金利 2% で約 2.2 倍、4% で約 1.5 倍(E059)
- 毎月 3 万円 x 20 年の乱数モデルでは、2 倍型(課税口座)の手取りの中央値は、1 倍(NISA)に比べて金利 2% で +193 万円、
  4% で −186 万円。元本割れの確率は 5% → 14〜20%(E059)

## 検証で引っかかった落とし穴

勝ちに見えた結果の多くは、次のどれかだった。新しい勝ちを見たら、まずここを疑う。

| 落とし穴 | 例 |
|---|---|
| 市場モデルの作り方の癖 | 合成の相場の逆張り・ブレイクアウト・スキャルピングの勝ちは、相場の作り方の穴だった(R002・R008・M003・M006) |
| 約定の決まりの甘さ | すでに越えていた逆指値を、その値段で約定させていた(E007。方向でたらめ版でも 30 年 +3,000 万円) |
| 1 本の歴史への当てはめ | 日足の EMA 交差は実データ 30 年で +37 万円、並べ替えた相場では t −0.15(E009) |
| 時期の性質 | 週足の逆張りは 2010〜2026 年だけ、順張りは 1994〜2010 年だけ勝つ(E048・E060) |
| 試した数 | 168 通りから拾った一番の t 2.4 は、偶然の最大と区別できない(E050・E053・E068) |
| 足の区切り | 4 時間足の区切りを 1 時間ずらすだけで、1 取引の損益が 2 倍変わる(E052) |
| 円安とスワップ | 買いに偏った型は、2012〜2026 年の円安とスワップで勝って見える。方向でたらめ版も勝つ(E011・E022) |
| LLM の記憶 | 過去の日付を渡すと、LLM は答えを知っている(E061) |
| 集計の誤り | 計算の設定がワーカーのプロセスに残り、別の計算に漏れていた(E068 で見つけて直した) |

## 手元で再現する

```bash
pip install -r requirements.txt
python -m pytest -q                              # テスト
python -m fxsim list                             # 市場モデル・戦略・業者の一覧
python -m fxsim run configs/quick.yaml           # 動作確認(数十秒)
python -m fxsim verify B049                      # 30 年の長期検証(数十分)
python -m fxsim.research.vol_band_fade --help    # 研究のスクリプトは fxsim/research/ に 1 実験 1 本
```

実データの一部(FRED の日足と金利)は `data/real/` にある。業者の足(1 分足〜日足)は再配布できないのでリポジトリに入れていない。
MT5 の口座を持っていれば `python -m fxsim fetch-mt5 configs/market_data/oanda-demo.yaml` で手元の DB に溜められる(`docs/TRADING.md`)。
