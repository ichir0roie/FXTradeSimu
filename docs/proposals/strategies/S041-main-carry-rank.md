# S041 main_carry_rank: 10 ペアを受け取りとボラの釣り合いで順位付けし、上から 4:3:2:1 の量で張る(S040 の順位版)

- 種類: 戦略 / 状態: 実装済み、保留(E028 で B047 を上回らなかった)
- 実装: `fxsim/strategies/main/carry_rank.py`(登録名 `main_carry_rank` v1)、動作ケース B048
- 親: S040(B047)

## 仮説
金利差が大きく、値の振れが小さく、スプレッドの軽いペアほど、スワップ狙いの建玉として安定する。安定面の条件を満たすペアを
「受け取りの年率 / 250 日ボラ」の順に並べ、上位ほど多く張れば、同じ口座でより多くの受け取りを小さい振れで取れる。

## 設計
| 部品 | 中身 |
|---|---|
| 安定面の条件 | 受け取り(業者の上乗せを引いた年率)≥ `min_carry`、250 日ボラの年率 ≤ `max_vol`(15%)、典型のスプレッド ÷ 1 日の受け取り ≤ `max_spread_days`(10 日) |
| 順位 | 条件を満たすペアを、受け取り ÷ 250 日ボラの高い順。毎日その日までの値で決め直す(後から見た上位を固定しない) |
| 量 | 上から `weights`(既定 4:3:2:1)x `unit`(1,000 通貨)。weights の数より下の順位には新規を出さない |
| 持ち続け | 順位は新規の判断のときだけ使う。持っている建玉は順位が変わっても、反対側のチャネル・金利差の下限割れ・向きの反転まで持つ(`drop_rank` 0)。量も入ったときのまま |
| 入り・守り | S040 のまま(20 日抜けで入り 10 日で出る、急変用の逆指値 ATR x 9、月初の 9 割の床、証拠金の上限 50%、スプレッドの門、swap_side_only) |

S040 には、順位の口(`rank_bar` / `allowed` / `entry_units` / `drop`)を足しただけで、B047 の成績は 1 円も変わらない。

## 2026-11 の並び(OANDA の点数、3 年のボラ)
USDCHF 買い 3.2% / 8.1%(0.39)、AUDJPY 買い 3.0% / 10.3%(0.29)、USDJPY 買い 2.3% / 9.7%(0.24)、EURUSD 売り 1.1% / 6.8%(0.17)、
GBPJPY 買い 1.2% / 8.6%(0.14)。NZDUSD はスプレッドの取り返しに 10 日、EURJPY・AUDUSD は受け取り 0.4% 以下、
GBPUSD・USDCAD は受け取る向きが無い。

E028(`docs/proposals/experiments/E028-carry-rank.md`)。

## 判定
保留。下限なしの「上位 5」は B047 より大きく悪い。B047 の下限を残すと直近の実データでは同じくらいだが、順位で量を変えても
シャープは上がらず、古い実データとランダムな相場ではドローダウンが大きい。常駐は B047 のまま。
