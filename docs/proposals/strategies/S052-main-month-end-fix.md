# S052 main_month_end_fix(月末のロンドン 16 時のフィキシングの後にドルを買う)

- 種類: 戦略 / 状態: 保留(癖は本物だが小さい)
- 実装: `fxsim/strategies/main/month_end_fix.py`(登録名 `main_month_end_fix` v1)、テスト `tests/test_month_end_fix.py`
- 動作ケース: B083(2 時間、損切り ATR x 3)、B084(同じで損切り ATR x 1 = 量 3 倍)
- 親: E061

## 仮説
月末は、ロンドン 16 時(WM/Reuters)のフィキシングに向けてドルが売られ、終わると買い戻される。E061 の研究の約定では、
フィキシングから 1〜2 時間のドル買いが対ドル 6 ペアで +2〜4 bp(素)、t 3、隣の日の同じ時刻には無い。

## 設計
- 1 時間足。月の最後の平日の、16:00 ロンドン(夏 15:00 UTC、冬 16:00 UTC)の 1 時間前に始まる足の終値で決め、
  フィキシングの足の始値で成行、hold 本後の足の始値で出る(既定 2)
- 向きは USDxxx なら買い、xxxUSD なら売り。ドルを含まないペアは取引しない
- 損切りの幅 ATR(24) x stop_atr(量を決めるだけ)。費用のゲートは使わない(1 回の見込みが 1〜2 pip で、3 倍の基準に届かない)

## 測り方
```bash
python -m fxsim pair-eval B083 --broker oanda
python -m fxsim pair-eval B083 B084 --broker oanda --pairs USDJPY EURUSD GBPUSD AUDUSD NZDUSD USDCHF USDCAD
```

## 結果
E061 の「3 本物のエンジン」。帰無との差は t 3.45〜3.82、期間ごとにプラス 75%、ドルの 7 ペア中 5〜6 本がプラス。
R1・R5 はプラスのパターンの割合(40〜57%)で不通過。取引の無いパターン(円のクロス、2010〜2014 年のスワップの決まり)が効いた。
損益は 100 万円の口座で年 0.12%(B083)〜0.3%(B084)。

## 判定
保留。値動きの癖としては本物(帰無より上、隣の日に無い、研究の約定とエンジンで同じ大きさ)だが、年 12 回 x 1〜2 bp で、
単独の戦略としては小さすぎる。ほかの戦略と同じ口座に足す小さな上乗せとしてなら使える。
