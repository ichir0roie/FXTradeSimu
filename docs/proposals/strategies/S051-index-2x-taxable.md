# S051 株価指数の 2 倍型を課税口座で毎月積み立てる

- 種類: 戦略(FX の外。株価指数の積立の試算) / 状態: 実装済み(2026-11-13、乱数モデルの試算のみ)
- 実装: `fxsim/research/leveraged_index.py`(`PLANS` の `S051`)、テスト `tests/test_leveraged_index.py`
- 比べる相手: S050(1 倍・NISA)。比較は E059
- 親: S050

## 仮説
株価指数の期待値がプラスなら、2 倍にすると上乗せ(株式リスクプレミアム)も 2 倍になる。ただし借りた分の金利、毎日の組み直しによる
目減り(ボラの 2 乗 x 2)、高い信託報酬、課税(2 倍型は NISA の成長投資枠の対象外)が引かれる。
ケリーの倍率は (期待リターン − 金利) / ボラ^2 で、指数 9%・ボラ 18% なら金利 2% で約 2.2 倍、4% で約 1.5 倍。
金利が高いと、2 倍は伸びが最大の倍率を越え、手取りの中央値で S050 に負けると予想する。

## 設計
- 毎日 2 倍を保つ投資信託を、毎月同じ額だけ課税口座で買い、最後に全部売って利益の 20.315% を払う
- 信託報酬 年 0.9%(国内の 2 倍型の水準の目安。商品ごとに違う)
- 1 か月の対数リターン = 2 x 期待リターン − 1 x 金利 − 信託報酬 − 4 x ボラ^2 / 2 + 2 x ボラ x 乱数(連続で組み直す近似)

## 測り方
E059 で S050 と同じ乱数で回す。金利 2% と 4% の両方で、手取りの中央値が S050 を上回るか、下から 10% と元本割れがどれだけ悪くなるかを見る。

```bash
python -m fxsim.research.leveraged_index --borrow 0.02 0.04
```

## 結果・判定
E059 を参照。金利 2% では中央値で S050 を上回り(+193 万円)、4% では下回る(−186 万円)。下振れはどちらでも大きく悪い。
