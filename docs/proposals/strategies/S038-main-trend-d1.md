# S038 本命の土台と 1 本目(main_trend_d1)

- 種類: 戦略 / 状態: 実装済み(検証中)
- 実装: `fxsim/strategies/main/base.py`(`MainStrategy`)、`fxsim/strategies/guards.py`(共通の対策)、
  `fxsim/strategies/main/trend_d1.py`(登録名 `main_trend_d1` v1)、帰無 `fxsim/strategies/main/null.py`(`main_direction_null`)。
  MT5 のテスター `fxsim/backtest/mt5/`(`docs/MT5.md`)
- 動作ケース: B045(malicious の費用、国内の MT5 口座のひな形 `jp_domestic`、並べ替えのブロック 500 日)
- 親: E012(4 枚の壁と回避策)、S006 / B007(日足の時系列モメンタム)

## 仮説
E012 で、日足の時系列モメンタムは費用の壁(1 取引 2.6 pip)を越える素の損益(+10 pip / 取引)を持っていたが、
スワップの上乗せ(年率 1%)と回転で消えた。共通の対策(壁 1〜3 の避け方)を全部入れて MT5 の口座の決まりで回せば、
少なくとも「負けない」ところまでは来る。勝つかどうかは信号の情報(壁 0)次第で、ここでは測るだけ。

## 設計
戦略の区分を分けた。これまでの手法の一覧は「基本検証」(`tier = basic`、`strategies/builtin/`)、MT5 に移す前提の戦略は
「本命」(`tier = main`、`strategies/main/`、MT5 のテスターで回す)。

本命の土台 `MainStrategy` は、サブクラスが `signals` で返す 3 つの列(向き・損切りの幅・見込みの値幅)だけで売買する。
共通の対策(`GuardConfig` の既定値):

| 対策 | 既定 | 避ける壁 |
|---|---|---|
| 量 = 損切りまでの損失が有効証拠金の 0.5%(固定比率)。建玉の総額は有効証拠金の 3 倍まで、証拠金の余力の 8 割まで | 0.005 / 3.0 | 3 量 |
| 費用の門: 見込みの値幅 ≥ 往復の費用(スプレッド + 滑り 0.5 pip x 2 + 手数料 + 20 日分のスワップの支払い)x 3 | 3.0 | 1 費用・2 スワップ |
| 回転の上限: 新規は直近 365 日で 24 回まで | 24 | 1 費用 |
| 終値の損切り + 遠くの非常用の逆指値(損切りの幅の 3 倍) | close_stop | 狩り・逆指値の滑り |
| ドローダウンの止め: 有効証拠金が山から 25% 下げたら新規を止める | 0.25 | 破綻 |
| ロールオーバーの前後 1 時間は新規を出さない(日足以上では効かない) | 1.0 | スプレッドの拡大 |

1 本目 `main_trend_d1` の信号は結果を見て調整していない定番の形: 終値が 200 日の移動平均より上で 60 日のリターンがプラスなら買い、
両方逆なら売り、ほかは持たない。損切りの幅は ATR(20) の 3 倍、見込みの値幅は ATR(20) x √20。

方向でたらめ版(`main_direction_null`)は、同じ戦略を MT5 のテスターで動かし、新規の向きだけを乱数にする
(手仕舞いの時期は元の信号で決める)。
