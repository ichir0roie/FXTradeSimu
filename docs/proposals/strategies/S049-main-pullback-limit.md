# S049 main_pullback_limit: 日足の押し目に、指値で待って入る(1 時間足で動かす)

- 種類: 戦略(本命の枠) / 状態: 実装済み(2026-11-13)。日足の版は不合格(E050)。日足未満・荒い時期だけの版は pair-eval 合格で候補(E052)
- 実装: `fxsim/strategies/main/pullback_limit.py`(登録名 `main_pullback_limit` v1)、テスト `tests/test_pullback_d1.py`
- 動作ケース: B064(指値 ATR x 0.5、両方向)、B065(成行の対照)、B066(受け取る向きだけ)
- 親: S048(main_pullback_d1)

## 仮説
E050 の格子で、押し目の成績を変えたのは損切り・利確ではなく入り方だった。日足の終値から ATR x 0.5 有利な値に指値を置いて
1 日待つと、1 取引 +2.3 bp が +8.5〜10.3 bp になる(10 ペア、2010〜2026 年、研究の約定)。

## 仕組み

| 引数 | 既定 | 意味 |
|---|---|---|
| slow / rsi_n / enter / exit / max_days | 200 / 2 / 10 / 50 / 10 | S048 と同じ(日足の値は 1 時間足から取引日ごとに作る) |
| limit_atr | 0.5 | 前の取引日の終値から ATR x これだけ有利な値に指値(0 = 成行) |
| expire_hours | 22 | 指値の期限 |
| stop_atr / tp_atr | 3.0 / 0 | 建値からの逆指値(サーバー)と利確の指値(0 = 置かない) |
| vol_ratio_min / vol_long | 0 / 250 | ATR(atr_n) / ATR(vol_long) がこれ以上の日だけ入る(0 = 見ない。B067 は 1.2、E051) |
| signal_hours / rolling | 24 / false | 信号の足の長さ(時間)。24 未満は日足未満の版で、UTC の時刻で切る。rolling は区切りを 1 本ずつずらした全部の位相をまとめて毎時判断する(E052) |
| decide_bars | 2 | 取引日が替わってから、この本数の足が確定したときに 1 日 1 回判断する(ロールオーバーのスプレッドを避ける) |

取引日はサーバー時刻(ニューヨーク + 7 時間)の日付。量は損切りで有効証拠金の 0.5% を失う量(guards.size_lots)。
コストゲート・回転の上限・口座の床は入れていない(1 日 1 回・年 5 回ほどなので)。

## 結果と判定
E050 を参照。pair-eval は B064・B065・B066 とも 5 条件すべて不通過。通しで回すと指値は成行より 1 取引 +4〜7 bp 良いが、
円の損益は 10 口座・16 年で +1.2 万円(t 0.21)。

荒い時期だけの版(B067、E051): 通しのエンジンで 1 取引 +57 bp・月ごとの t 2.82。pair-eval は R1・R5 が不通過(取引が少ない)。候補として証拠を積む。

日足未満の版(B068〜B075、E052): 4 時間の足・荒い時期だけで、B068・B069・B070・B073・B074 が pair-eval 合格。候補は B073。
