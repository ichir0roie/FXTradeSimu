# S032〜S036 複数通貨の手法(キャリー・モメンタム・バリュー・トレンド・勾配ブースティング)

- 種類: 戦略(と、それを回すための市場モデル・エンジン)
- 状態: 実装済み
- 実装:
  - 戦略 `xs_carry`(S032)・`xs_momentum`(S033)・`xs_value`(S034)・`basket_trend`(S035)・`xs_gbdt`(S036)、
    帰無 `basket_direction_null`(S901)。共通の部分は `fxsim/strategies/basket.py`
  - 市場モデル `basket_real`(R009)・`basket_bootstrap`(R010)・`basket_placebo`(R011)・`basket_random_walk`(M007)、
    `fxsim/markets/models/basket.py`
  - エンジン `fxsim/backtest/portfolio.py`(複数ペアを 1 つの口座で回す)
  - データ `data/real/fx_jpy_crosses_d1_fred.csv`(対円 7 ペアの日足 1999〜)・`data/real/short_rates_monthly_fred.csv`
    (8 通貨の短期金利の月次)。`python -m fxsim fetch-fred` で取り直せる
- 親: S020 carry_trade、S006 tsmom、long_term_value(1 ペアの時系列版)。調査 `docs/TRADING_LANDSCAPE.md` の 2・3・6

## 仮説
機関の主流の手法(`docs/TRADING_LANDSCAPE.md` の 2)は、1 ペアではなく複数の通貨の順位で取引する。
1 ペア(USDJPY)の時系列版はどれも不合格だった(E009)。通貨どうしの相対で持てば、円そのものの上げ下げ(2016〜2026 年の円安)に
頼らない優位性が見えるかもしれない。

- S032 キャリー: 金利の高い通貨を買い、低い通貨を売れば、スワップの分だけ勝つ。ただし危機で高金利通貨がまとめて急落する
- S033 モメンタム: 3 か月強かった通貨はしばらく強い
- S034 バリュー: 5 年で下がった通貨は戻る(物価のデータが無いので名目の長期の反転で代用)
- S035 トレンド(CTA の型): 7 ペアに分散すれば、1 ペアの tsmom より安定する
- S036 勾配ブースティング: 上の特徴量(リターン・ボラ・金利差)をまとめて学習すれば、個々の規則より良い順位が付く

## 設計
- 対円 7 ペア(USD・EUR・GBP・AUD・NZD・CAD・CHF)。円建てなので損益をそのまま足せる。日本の個人の取引そのもの
- 順位の手法(S032〜S034・S036)は上位 2 を買い・下位 2 を売る。買いと売りが同数なので円全体の向きは打ち消す。
  21 日ごとに入れ替え、1 ペアの建玉の金額 = 初期資金 100 万円 x 1.5 ÷ 4(1 ペアの戦略の 1 万通貨とほぼ同じ総額)
- S035 は順位ではなくペアごとの半年の向き。ボラの逆数で量をそろえ、口座全体の年率 10% を目安にする(総額は最大 3 倍)
- S036 は 7 ペアをまとめた 1 つのモデル。walk-forward(最初は 3 年分で学習、以後 1 年ごとに学習し直す)。
  学習に使うのは、その時点で答え(21 日先)が出ている標本だけ
- 市場: 実データ 1 本、並べ替え(全ペア同じ日付の並び。ペアどうしの相関は残る)、偽薬(全ペア共通の日ごとの符号)、
  完全ランダム(実データの共分散を持つ正規乱数)
- 金利は FRED の 3 か月物の銀行間金利の月次。月 M の平均は翌月 1 日から有効(判断に未来の値を使わない)。
  合成の相場にも実際の日付の金利を当てはめる(1 ペアの carry_trade と同じ)
- スプレッドは国内の業者の原則固定の幅を参考にした概算の固定値(USDJPY 0.2〜CHFJPY 1.6 pip)。日足の 2 点だけで、足の中の経路は無い

## 測り方
```bash
python -m fxsim verify B011 --years 30 --seeds 1-10 --block-days 250   # S032(B012〜B015 も同じ。B013 はブロック 1260 日)
python -m fxsim run configs/basket_methods.yaml                        # E010: ブローカーごとの差と、試した数の補正
python -m fxsim overfit <E010 の run_key> --market basket_bootstrap
```
- 合否は E002 の C1〜C4(malicious ブローカー)。帰無は basket_direction_null(ペアごとの向きだけ乱数)
- C1 が通って C3(偽薬より上)が落ちるなら、合成の作り方の癖か、カレンダーに固定した金利(スワップ)の分
- キャリーは C2(方向でたらめ版より上)が「金利の順位に情報があるか」になる。スワップは方向でたらめ版では打ち消し合う
- 参考: 実データ 1 本の Deflated Sharpe(試した数 = 登録済みの戦略の数)

## 判定
5 本とも不合格(malicious ブローカー)。

1. キャリー(S032): 勝ちの中身はスワップだけ。実データでは素の損益がほぼ 0 だった。並べ替えると、高金利通貨の値下がりで
   素の損益が −41 万になり、金利差の大部分を吐き出す(金利の差は為替の値下がりで埋め合わされる、という金利平価に近い形)。
   偽薬・完全ランダムで勝つのは、値下がりが起きない相場でスワップだけもらうから(C3 が大きくマイナスなのはこのため)
2. モメンタム(S033): 4 本の設定(21・63・126・252 日)のどれも、実データ・並べ替えで素の損益がマイナス。
   この 27 年の対円 7 ペアでは、通貨どうしの相対の強さは続かなかった
3. バリュー(S034): 素の損益はどの相場でもほぼ 0。名目の長期の反転では情報が無い(物価で調整した本来のバリューは未検証)
4. トレンド(S035)と勾配ブースティング(S036): 実データと並べ替えで素の損益が +28〜37 万あり、ドリフトを抜いても残る。
   偽薬と完全ランダムでは消えるので、実データの数週間〜数か月のトレンドの塊(時系列の自己相関)を拾っている。
   ただし malicious のスワップの上乗せ(−42 万)でほぼ消え、fair でも実データ 1 本の Deflated Sharpe は 0.34〜0.63
   (E010 の 16 本の中で選んだ一番としては偶然で説明がつく)。C2(方向でたらめ版より上)は通る

1 ペアの手法(E009)と同じく、単純な規則で安定して勝つものは無い。違いは、トレンドと勾配ブースティングが
「素の損益は本物らしいが、費用(特にスワップの上乗せ)を超えるほど大きくない」こと。

## 次の一手

- 建玉の総額を下げて、スワップの上乗せと素の損益の比を見る(上乗せは総額に比例、素の損益も比例するので比は変わらないはず。確かめる)
