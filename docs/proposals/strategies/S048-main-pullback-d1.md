# S048 main_pullback_d1: 長いトレンドの向きに、深い押し目で入り数日で出る

- 種類: 戦略(本命の枠) / 状態: 実装済み(2026-11-13)。verify は合格、pair-eval は不合格。採用の候補にはしない(E048)
- 実装: `fxsim/strategies/main/pullback_d1.py`(登録名 `main_pullback_d1` v1)、テスト `tests/test_pullback_d1.py`。
  10 ペアの口座版は `main_trend_free` の `signal: pullback`
- 動作ケース: B060(両方向)、B061(受け取る向きだけ)、B062・B063(10 ペアの口座版)

## 仮説
E048 のふるい(日足の 184 型)で、発見(1996〜2013)と確認(2014〜2026)の両方でプラスだったのは押し目の族だけ。
長い向きには順張り、短い行き過ぎには逆張りを重ねるので、2014 年前後の性質の反転に左右されにくい。

## 仕組み(教科書どおり。結果を見て数字を選んでいない)

| 引数 | 既定 | 意味 |
|---|---|---|
| slow | 200 | 終値がこの日数の移動平均より上なら買いだけ、下なら売りだけ |
| rsi_n / enter | 2 / 10 | RSI(2) が 10 を割ったら買い(売りは 90 を越えたら) |
| exit / max_bars | 50 / 10 | RSI(2) が 50 を越えるか、10 本たったら出る |
| atr_n / stop_atr | 20 / 3.0 | 終値の損切りの幅(ATR x 3)。量はこの幅で決まる |
| trend | true | false なら移動平均を見ない(ただの逆張り。対照) |

共通の対策(guards)は既定のまま。持つ日数の見込みだけ 3 日、回数の上限を年 40 回にしている。

## 結果と判定
E048 を参照。B060 は verify(USDJPY 30 年)を C1〜C5 すべて通ったが、実データ 10 ペア x 5 期間では R1・R5 が不通過。
素の損益は 1 取引 +5.7 pip(方向でたらめ版 −2.4 pip)、費用 2.7 pip。Deflated Sharpe 0.10。
