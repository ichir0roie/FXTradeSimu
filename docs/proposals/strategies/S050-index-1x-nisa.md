# S050 株価指数の 1 倍を NISA で毎月積み立てる

- 種類: 戦略(FX の外。株価指数の積立の試算) / 状態: 実装済み(2026-11-13、乱数モデルの試算のみ)
- 実装: `fxsim/research/leveraged_index.py`(`PLANS` の `S050`)、テスト `tests/test_leveraged_index.py`
- 比べる相手: S051(2 倍型・課税口座)。比較は E059
- 親: なし。FX の値動きには期待値が無く、株価指数にはある(株式リスクプレミアム)という整理から

## 仮説
株価指数は持つだけで期待値がプラス。費用(信託報酬 0.1%)と税(NISA で 0)を抑えた 1 倍の積立が、レバレッジを掛ける案の基準になる。

## 設計
- S&P500 などの指数に連動する 1 倍の投資信託を、毎月同じ額だけ NISA で買い、最後に全部売る
- 信託報酬 年 0.1%。NISA の枠(年 360 万円・生涯 1,800 万円、買った額)を越えた分は、同じ中身を課税口座で持つ(利益の 20.315%)
- 指数の値動きは乱数のモデル(E059 の設計を参照)

## 測り方
E059 で S051 と同じ乱数(共通乱数)で回し、手取りの分布(下から 10%・中央値・上から 10%)・元本割れの割合・基準価額の最大 DD を比べる。

```bash
python -m fxsim.research.leveraged_index
```

E059 を参照。基準の案として残す。
