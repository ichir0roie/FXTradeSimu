# S007–S031 よくある投資手法

- 種類: 戦略 / 状態: 実装済み(評価は E006)
- 実装: `fxsim/strategies/builtin/*.py`(1 ファイル 1 手法。賭け方だけは `betting.py` にまとめ、賭け方ごとの名前でも登録)、
  賭け方 `fxsim/strategies/staking.py`、指標 `fxsim/strategies/indicators.py`、ナンピン・積み増し `ctx.add`

## 仮説
個人の FX でよく使われる手法を、古典から新しめのものまで同じ物差しで回すと:
1. **悪意ある相場(malicious)と、実データの範囲でランダムにした相場では、どれも素の優位性がほぼ 0**。費用(スプレッド・滑り・
   ブローカーの悪意)の分だけ負け、回転が速いほど負けが大きい
2. **ギャンブルの賭け方は期待値を変えない**。マーチンゲール・ナンピンは「勝率は高いが、まれに口座の大半を失う」分布になり、
   10 年あれば破綻に近いところまで行く。パーリーは逆に「勝率は低いが、まれに大きく勝つ」
3. 実データ 1 本で勝つ手法(円安のトレンドに乗るもの、キャリー)は、並べ替えた別の歴史(real_bootstrap)では勝たない
4. 五十日の仲値トレードのような「時刻の癖」は、合成の相場には入れていないので勝てない(勝てば偶然か、作り方の穴)

## 仕組みの追加
- `ctx.add(units, sl=, tp=, sl_from_average=)`: 同じ向きに足す(ナンピン・積み増し)。取得単価・手数料・滑りは数量で加重平均して
  1 つの建玉にまとめる。利確は平均からの距離、損切りは足した価格からの距離(`sl_from_average` なら平均から)
- `ctx.trades`(決済済みの取引)と `ctx.base_units`(1 単位の量): 賭け方が前回の結果を見るため
- 先読み検査の判断の記録に数量を入れた(賭け方の量が未来を見ていないことも確かめる)
- 実装しなかったもの: 複数の建玉を別々に持つ型(トラリピ・グリッドのように、値段ごとに別々に利確する注文の束)。
  エンジンが 1 建玉なので、ナンピンは平均取得単価にまとめる形だけ

## 測り方
```bash
python -m fxsim check-lookahead
python -m fxsim run configs/methods.yaml      # E006
python -m fxsim report <run>
```
- 判定は CLAUDE.md の戦略の物差し(パターン単位の t・中央値・プラスの割合、malicious ブローカーの平均)
- ギャンブルの賭け方は、損益の平均より **分布の形**(プラスの割合と最小値、最大 DD)を見る

## 結果(E006、run #12)
- malicious ブローカーで総合がプラスなのは buy_and_hold・carry_trade・carry_trend だけ(円安と金利差に乗ったもの)
- 回転の速い手法(scalping・london_breakout・pivot_reversal など)は費用で大きく負ける
- ギャンブルの賭け方は全部破綻(fair でも 32 パターン中プラスは nanpin_martingale の 3 本だけ)。仮説 2 のとおり期待値は変わらず、分布の形だけが変わる
- RSI・ストキャスの逆張り(実データ系)と scalping(malicious)の勝ちは市場モデルの穴(R008 / M006 で直す)

詳しくは `docs/proposals/experiments/E006-common-methods.md`。

## 結果(E008、市場 v4・エンジンの修正後)
- RSI・ストキャスの逆張りと parabolic_sar の勝ちは消えた(R008・M006 と損切りの約定の修正)。malicious ブローカーで総合がプラスなのは
  buy_and_hold・carry_trade・carry_trend の 3 本だけ(E006 と同じ)
- 賭け方は fair でも 91〜100% のパターンが破綻(E007 の破綻の列)
- carry_trend・parabolic_sar の 30 年の検証は E009(どちらも不合格。carry_trend は方向でたらめ版より上だけ合格)

詳しくは `docs/proposals/experiments/E008-common-methods-v4.md`、候補の一覧は `docs/CANDIDATES.md`。
