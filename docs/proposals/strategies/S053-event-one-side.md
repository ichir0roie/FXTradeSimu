# S053 event_one_side(大きく動く時に片側だけ入る。利確のみ・逆指値なし・負けは落ち着いてから閉じる)

- 種類: 戦略 / 状態: 却下
- 実装: `fxsim/strategies/builtin/event_one_side.py`(登録名 `event_one_side` v2。v2 で trigger = claims を足した。nfp・spike の動きは v1 と同じ)。雇用統計の日付の決まりは `fxsim/calendar.py`
  (`nfp_dates`・`nfp_bar_start`、E062 から移した。E062 の数字は回し直して一致)
- 動作ケース: B085〜B091
- 親: E062・E063(研究の約定で不合格)。利用者の最初の案を、本物のエンジンにそのまま載せたもの

## 仮説
研究の約定(E062・E063)では、片側・逆指値なし・跳ねたら利確・負けは落ち着いてから閉じる形は、勝率は高いが平均はマイナスだった。
本物のエンジン(記録のスプレッド、約定の決まり、スワップ)でも同じになる。

## 設計
- 1 時間足。trigger = nfp(米雇用統計の足の始値で入る)/ spike(平常の spike_k 倍跳ねた足が確定したら、次の足で跳ねた向きに入る)
- 向き: nfp は 20 日の値動きの向き、spike は跳ねた向き。pair-eval の方向でたらめ版が帰無
- 利確: 物差し x tp_mult(nfp は直近 12 回の発表の足の幅の中央値、spike は直近 480 本の幅の中央値)。逆指値は置かない
- 手仕舞い: calm(入った後の足の幅が直近 480 本の中央値以下に戻ったら閉じる)/ 5d(利確まで最長 120 本)

| B085 | nfp | 0.5 | calm | 1 万通貨 |
| B086 | nfp | 0.25 | 5d | 1 万通貨 |
| B087 | nfp | 0.5 | calm | 1,000 通貨(量を小さくした版) |
| B088 | spike(3 倍) | 1.0 | calm | 1 万通貨 |

## 測り方
```bash
python -m fxsim pair-eval B085 B086 B087 B088 B089 --broker oanda
```
