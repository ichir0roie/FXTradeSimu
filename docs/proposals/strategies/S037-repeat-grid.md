# S037 リピート系(グリッド)

- 種類: 戦略
- 状態: 実装済み
- 実装: `fxsim/strategies/builtin/repeat_grid.py`(登録名 `repeat_grid` v1)。エンジンに一部決済 `ctx.reduce(units)` を足した
- 親: nanpin_martingale(E006)。調査 `docs/TRADING_LANDSCAPE.md` の 2(日本の個人の主流の自動売買)・5.3(売り文句)

## 仮説
リピート系(トラリピ・ループイフダンの型)は「レンジ相場で細かく利益を積む」と売られる。中身は損切りなしのナンピンを
値幅ごとに分けたもので、期待値は変わらず、分布の形(勝率が高く、まれに大きく負ける)だけが変わるはず。
買いのリピートの成績は、その期間に円安だったか(相場の向き)でほぼ決まる。

## 設計
- 起点から 1% 刻みに 20 段の買いの値段を並べ、終値がその段以下なら 1 段(1,000 通貨)買い、1 段上で利確する。損切りなし
- 全段が空のまま 60 日たち、値段がレンジの上にあるときは、今の終値を新しい起点にする(利用者が設定し直すのを真似る)
- 売りのリピート(B017)は上下を反転したもの
- 近似: 本物は指値だが、ここは日足の終値で判定し、次の足の始値の成行で約定する(足の中の往復は取りこぼす)。
  建玉は平均取得単価で 1 つにまとめ、段ごとの利確は一部決済。損益の合計は段ごとに持つのと同じだが、
  勝率は段ごとに数える業者の画面より低く出る(1 段ごとに見れば、利確した段はすべて勝ち)

## 測り方
```bash
python -m fxsim verify B016 --years 30 --seeds 1-10 --block-days 250   # 買い
python -m fxsim verify B017 --years 30 --seeds 1-10 --block-days 250   # 売り
```
- C1〜C4(malicious ブローカー)に加えて、破綻の割合・最大 DD・パターンごとの損益の幅を見る
- 方向でたらめ版(最初に建てる向きだけ乱数)との差が 0 に近ければ、成績は向きの運(期間のドリフト)で決まっている

## 判定
却下(手法としての優位性は無い)。B016 の「合格」は検証の仕組みの穴による誤判定。

1. 偽薬(方向の情報もドリフトも無い相場)で、買いのリピートの素の損益は −0.3 万。値幅を取る仕組みそのものは何も生まない
2. 実データ・並べ替えの勝ちは、1996→2026 年のドル円の上昇(約 107→158 円)に買いで乗った分と、金利差のスワップ。
   買い持ち(B018)と同じ中身で、成績もほぼ同じ(並べ替え +141 万 / +134 万、偽薬 +46 万 / +46 万)
3. 検証の C2(方向でたらめ版より上)は、方向でたらめ版の半分が売りになり、ドリフトとスワップを払う側に回るので、
   買いに偏った戦略なら必ず通る。C3(偽薬より上)だけが安全弁で、B016 は t 2.05、B018 は t 1.61 と境目の上下に分かれただけ
4. 売りのリピート(B017)は、同じ仕組みで向きが逆なだけで、円安の 30 年に売りの段が全部埋まったまま抜けられず、
   スワップを払い続けて破綻した(実データ・日中ランダムで 100%、並べ替えで 80%)。素の損益は実データで +1 万とほぼ 0
5. リピート系の売り文句(「レンジで細かく稼ぐ」「放置で」「勝率が高い」)に対する答え: 勝ちも負けも、その期間の相場の向きと
   金利差で決まる。勝率 75% でも最大 DD は平均 45%(売りは 90%)。`docs/TRADING_LANDSCAPE.md` の 5.3
