# M003 malicious

- 種類: 市場モデル / 状態: 採用(v1)。穴あり
- 実装: `fxsim/markets/models/malicious.py`(`malicious` v1)= stylized + crowd_squeeze + false_breakout + stop_hunt
- 親: M002

## 仮説
「相場は、いま多数派の群衆が一番痛がる方へ動く」。群衆の構成 w(順張り勢 / 逆張り勢、外からは見えない)を
ゆっくり動かし、ダマシ・ストップ狩りの結末を w で決めれば、決め打ちの順張りも逆張りも安定して勝てない。

## 経緯(調整の記録)
1. ダマシ = 常に戻す、ストップ狩り = 常に戻す、で組んだ → 分散比 0.74、逆張りが年 +1,600 pip(素のシャープ 1.8)。悪意ではなく癖
2. ダマシに「走り」、ストップ狩りに「連鎖」を足した → 今度は順張りが年 +4,000 pip。連鎖の幅が戻りより大きすぎた
3. 結末の確率を w で決め、幅の期待値を釣り合わせた。既定値: crowd strength 0.06、stop_hunt revert_prob 0.65・cascade (0, 6)、
   false_breakout prob_range 0.45・follow_prob 0.2 → 3 年 x 6 パターンで素のシャープの絶対値の最大 0.63

## 結果(E001、run #1、10 年 x 8 パターン)
| 戦略 | fair の損益中央値 | malicious ブローカー |

| random_entry | −17.5 万円 | −57.1 万円 |
| ma_cross (H1) | +55.2 万円 | +30.1 万円 |
| donchian_breakout (H1) | **+109.1 万円** | **+83.6 万円** |
| bollinger_reversion (H1) | +34.9 万円 | −22.2 万円 |

- 現実らしさ 55.9(10 年では 1 時間足の尖度が 52 で目安超え。M002 と同じ理由)
- **順張りに穴が残っている**。長い期間・多いパターンで見ると、ブレイクアウトが安定して勝つ(8 パターン中 7 本プラス)。
  3 年 x 6 パターンの調整では見えなかった
