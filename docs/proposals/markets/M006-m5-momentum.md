# M006 malicious の 5 分足の勢い(malicious v4)

- 種類: 市場モデル / 状態: 採用(FalseBreakout の分)/ StopHunt の分は保留
- 実装: `fxsim/markets/components/malice.py` の `FalseBreakout`(`move`、`run_delay`、`jump_minutes`)、
  `fxsim/markets/blocks.py::apply_quick_moves`、性質 `vr_m5_h1`(`fxsim/markets/evaluation.py`)、パネルに scalping と rsi_reversion(`fxsim/cli.py`)
- 親: M004(malicious v2)、M005(v3)。きっかけは E006 の「malicious の 5 分足の勢い」

## 仮説
E006 で、scalping(5 分足、20 EMA の向きへ直近 6 本の高安抜け、±5 pip)が malicious でコスト抜きの年 +807 pip(t = 10)を出していた。
M004 の検査は 1 時間足以上の戦略だけなので、分単位の勢いは見えていなかった。悪意の部品のどれかが数十分の勢いを作っている。

- 罠(戻し)も走りも、どちらも 5 分足の勢いを作る。どちらも「ずれを 3〜12 ブロック(45 分〜3 時間)かけた直線で入れる」
  (`apply_block_increments`)ので、動き出しを見てから乗れば残りが取れる。罠の戻しも、それ自体は反対向きの動き
- 走りに罠と同じ待ち時間を入れるだけ(`run_delay`)では変わらない(+1,254)。時間差ではなく、ずれの入れ方が原因
- 15 分(1 ブロック)で入れても +1,183。1〜3 分でも、5 分足の区切りをまたいだ分だけ残りが取れる(+494)
- ずれを **1 分で入れる**と、ストップ狩りなしで −84(t −0.7)

## 設計(v4)
`FalseBreakout(adapt_gain=1.0, move="jump", run_delay=True, jump_minutes=(1, 1))`
- 罠も走りも、抜けた後 `delay_blocks`(15〜60 分)待ってから、そのブロックのランダムな分で全量を 1 分で動かす
- 確率(局面・群衆・適応)は v3 のまま
- 実際のダマシの戻しやストップの走りも一気に起きることが多いので、現実らしさとも矛盾しない
- v3 の入れ方は `{"false_breakout": {"move": "drift", "run_delay": false}}`

性質 `vr_m5_h1` = Var(1 時間足) / (12 Var(5 分足)) を記録に足した(採点はしない)。

## 判定
FalseBreakout の分は採用(malicious v4)。scalping の残り(+0.38)は StopHunt から来ている。

## StopHunt の分(保留)
- 1 分で入れた FalseBreakout + StopHunt で scalping +485 pip/年(2 年 x 12)
- ヒゲの立ち上がりを 1 分にしても、戻りだけ(+282)・連鎖だけ(+725)・戻りの時定数を 1〜2 分(+517)のどれでも残る
- ストップ狩りの前後 60 分の取引だけを見ると、差し引きでほぼ 0(年 +40)。残りは、ストップ狩りの無い時間帯の取引に
  1 取引あたり +0.06〜0.10 pip で一様に乗っている(年・売り買いで差が無い)。ストップ狩りが水準(キリ番・直近の高安)の
  まわりの値動きの形を全体に変えている、と読んでいるが、仕組みは未解明
