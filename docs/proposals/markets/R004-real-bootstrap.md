# R004 real_bootstrap

- 種類: 市場モデル / 状態: 採用
- 実装: `fxsim/markets/models/real_based.py`、部品 `RealSkeleton(mode=bootstrap)`

## 仮説
実データの日次リターン(と足の形)を 20 日のブロック単位で並べ替えれば、ボラの塊を残したまま、
実データとは別の筋書きの相場を作れる。実データ 1 本への過剰適合を見抜くのに使う。

## 結果(E001)
- 現実らしさ 89.7
- 実データで勝った日足の戦略(donchian_d1)は、ここでも中央値 +12.0 万円(fair)/ +4.7 万円(malicious)。
  実データだけの偶然ではなさそうだが、パターン単位の t は 2 未満
- R002 と同じく、日中は橋で合成しているので H1 の逆張りが勝つ(同じ疑い)
