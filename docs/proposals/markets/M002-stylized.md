# M002 stylized

- 種類: 市場モデル / 状態: 採用(悪意なしの現実的な基準)
- 実装: `fxsim/markets/models/stylized.py`(`stylized` v1)

## 仮説
時間帯の季節性・ボラの塊・裾の厚さ・局面の入れ替わり・指標・週明けの窓・可変スプレッドを入れれば、
実際の為替の統計的性質(docs/MARKET_MALICE.md の目安)に収まる。

## 結果
- 3 年 x 3 パターン: 現実らしさ 98.4(目安をほぼ全部満たす)
- 10 年 x 8 パターン(E001): 50.4。1 時間足の尖度が 64 で目安(3–30)を超える。期間が長いと大きな指標ショックを引く回数が増えるため。
  目安の上限が短い期間を前提にしている可能性もある
- 逆張りに穴: bollinger_reversion(H1)の損益中央値 +62 万円 / 10 年(fair)。原因は `range_reversion`(半減期 16 時間)。
  外すと素の利益は年 +926 pip → +129 pip に下がる(3 年 x 3 パターン)

## 次の一手
