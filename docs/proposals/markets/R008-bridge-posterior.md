# R008 足の中の荒れ方から日足のリターンが漏れる問題(real_* v4)

- 種類: 市場モデル / 状態: 採用
- 実装: `fxsim/markets/components/real.py` の `AnchorBridge`(`calibrate_vol: posterior`、`clock: expected`、`vol_spread: 0.7`)
- 対象: real_bridge / real_bridge_malicious / real_bootstrap / real_bridge_placebo(すべて v4)
- 親: R005(real_* v2)、R007(v3)。きっかけは E006 の「実データ系の足の中の短い戻り」

## 仮説
E006 で、real_bridge・real_bootstrap の 1 時間足の RSI・ストキャスの逆張りが、コスト抜きで年 +450〜730 pip(t = 5〜13)勝っていた。
R005 の 24 時間の分散比の検査は通っているので、線形の自己相関ではない。

AnchorBridge v2〜v3 は、足の中の実現分散を「(1 − 0.6) x 局所ボラ² + 0.6 x その足のリターン r²」に合わせていた。
これだと足の中の荒れ方から |r| が漏れる。荒れ方が局所ボラより小さい日は |r| も小さいと分かり、終値へ引き戻される(戻り)。
荒れた日は |r| が大きいと分かり、走る。重み 0.6 はボリンジャー 1 本の素の優位性が 0 になる値として選んでいたが、
足の中の荒れ方を見て売買する RSI・ストキャスには穴が残っていた。

- 足の中の部品(指標・裾の厚さ・確率ボラ・季節性・急落)を 1 つずつ外しても変わらない。骨格への合わせ込みだけが原因
- 偽薬(符号でたらめ)でも出るので、実データの性質ではなく作り方の癖
- day_weight をどう選んでも、3 本が同時に 0 にはならない

診断: 日を「前半の実現分散 / 直前 20 日の実現分散」で 5 つに分け、E[r²] / E[足の中の実現分散] を見る。
ランダムウォークと骨格に合わせない版は 1.0 前後で平ら。v3 は 0.45 → 1.29(静かな日は戻り、荒れた日は走り)。

## 設計(v4)
1. 足の中の振れ幅 g を、r とは独立な事前分布から作り、r を見た事後分布で引く(`calibrate_vol: posterior`)。
   事前分布は ln g² ~ N(ln L² − s²/2, s²)。L² は**直前** 21 本の r² の平均(その足と、それより後は使わない)。
   r ~ N(0, g²) の尤度を掛けた事後分布から引く。こうすると「g が分かっても r は N(0, g²)」なので、
   足の中の経路は自分の過去だけを見ればブラウン橋 = ブラウン運動と同じ分布になる(正規の場合)
2. 終値とのずれを配る時計を、実現した dx² から事前の分散 vol²(季節性・確率ボラ・指標の後のボラの跳ね上がり込み)に変えた
   (`clock: expected`)。dx² に比例させると、ジャンプのような大きな 1 歩に、その日の残り(未来)を含んだ補正が大きく乗る
3. 足ごとの伸縮も、実現分散ではなく「事前の分散 + その足のジャンプ²」に合わせる

途中で試してやめたもの:
- 事前分布を経験分布に合わせる(正規分布の分散の混合を格子の上で EM、NPMLE)。偽薬で逆張りが +600 pip(t = 5)。
  局所ボラを前後の窓で測っていたため、荒れる時期の直前に g だけが先回りして大きくなっていた
- 局所ボラを中央値で測る: かえって悪化
- 純粋な正規分布の模型(`r` を混合から合成)では事後分布の方式は前向きの模型と同じ予測可能性になり、理屈は確かめた。
  実データのリターンに対して残る分は、事前分布の幅 s² で釣り合いを取る
