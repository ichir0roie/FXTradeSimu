# R009 足の中の振れ幅の事前分布の中心(real_* v5)

- 種類: 市場モデル / 状態: 採用(2026-11-10)
- 実装: `fxsim/markets/components/real.py` の `AnchorBridge`(`prior_long_window` 250、`prior_long_weight` 0.25)、
  `_posterior_goal`。real_bridge・real_bridge_malicious・real_bootstrap・real_bridge_placebo を v5 に
- 親: R008(足の中の振れ幅を事後分布で引く、v4)、E011・E012(日中の順張りが偽薬でも勝っていた)

## 仮説
E011 の検証で、1 時間足のドンチャン・4 時間足の平均足・15 分足のロンドンブレイクは、並べ替え(real_bootstrap)で
素の損益 / 取引がプラス(+1.48 / +1.94 / +0.55 pip、t 3.6 / 2.9 / 3.2)だった。日足の値動きの構造を壊した偽薬でも
ほぼ同じだけ残る(+1.01 / +1.38 / +0.52)ので、日足の構造ではなく、日中の足の合成の仕方が作った穴と考えた。

## 仕組み(調べて分かったこと)
`_posterior_goal` は、骨格の足ごとの足の中の分散 g² を、事前分布 ln g² ~ N(ln L² − s²/2, s²) と、その足のリターン r から
事後分布で引く。中心の L² は直前 21 本の r² の平均。これが偏った見込みだった:

- ボラは平均回帰し、21 本の推定はぶれる。30 年の USDJPY で E[r² / L21²] = 1.22
- 静かな時期の後(L が小さい)は、実際の日の動きが g² の見込みより大きい。終値へのずれの補正(期待の分散の時計で配る)が、
  雑音に比べて大きな一方向のドリフトになり、その日は日中にトレンドが出る
- 荒れた時期の後(L が大きい)は g² が大きすぎ、その日は日中に戻る
- 全体の E[r²] / E[g²] は 1.00 なので、24 時間の分散比の検査(R005 / R008)では見えない

直前 21 本の L の 5 分位(小 → 大)ごとの E[r²] / E[g²](30 年、s² = 0.7):

| 中心 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| v4: L21² | 1.46 | 1.27 | 1.15 | 0.95 | 0.85 |
| v5: 0.5 L21² + 0.5 L250² | 1.04 | 1.01 | 1.03 | 0.94 | 0.99 |

偽薬の経路(30 年 x 3 本)で、日の前半の向き x 後半の動き(トレンドの代わりの指標)は、L の 5 分位ごとに
+4.9 / +5.0 / +2.2 / −2.1 / −2.7 pip / 日(全体 +1.46、標準誤差 0.44)。順張りが差し引きで勝つ。

外したもの(調べたが原因ではなかった): 足の中の部品(季節性・確率ボラ・薄商い・指標・裾の厚さ・フラッシュクラッシュ)を
全部外しても穴は残る。vol_spread はどの値でも消えない(戻りと勢いの釣り合いが変わるだけ。R008 の表と同じ)。
中心を一律に c 倍(c = 1.2)すると戻りの側に行き過ぎる(偏りはボラの水準によるので、一律の倍率では直らない)。

## 設計
中心を (1 − w) L21² + w L250²(どちらも直前の窓、因果的)にする。長い窓 250 本。`prior_long_weight: 0` で v4 と同じになる。
重み w は 0 / 0.25 / 0.5 / 0.75 を回して、単純な規則の素の損益が一番 0 に近いもの(0.25)にした(下の結果)。
上の 5 分位の比の表は w = 0.5 のもの。回帰で当てはめた係数(r² ~ 1 + L21² + L250²、[8.8e-6, 0.55, 0.24])でも
5 分位の比は 0.91〜1.05 で大差ないので、単純な混ぜ方にした。

## 測り方
`configs/r009_anchor_prior.yaml`: 並べ替え(250 日ブロック)と偽薬で、v4 と v5 を同じシードで比べる(30 年 x 6、fair)。
日中の順張り 4 本(B002・B020・B029・B023)の素の損益 / 取引が、方向でたらめ版の水準(≈ 0、|t| < 2)に下がるか。
R008 の逆張りの組(RSI・ストキャス・ボリンジャー)に戻りの穴が戻ってこないか。

## 判定
採用(w 0.25、real_* v5)。並べ替え・偽薬とも、7 本の |素の損益| の合計が一番小さく(4.72 / 3.78。v4 は 5.42 / 5.98)、
並べ替えの最大の |gross_sharpe| は目安の 0.3 を下回った(0.21)。偽薬の最大はロンドンブレイクの 0.32 で、これは別の穴として残す。
6 本のパターンでの比較なので、1 本あたりの数字の差(±0.5 pip 程度)は雑音の大きさに近い。重みは 0.25 の近くなら大差ない。

E011 の日中の戦略の判定(v4 の相場)は古くなった。影響の大きい B002・B020・B023・B029 は v5 で検証し直す。
