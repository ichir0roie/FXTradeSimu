# M005 異常な値動きと薄商い(stylized v2 / malicious v3)

- 種類: 市場モデル / 状態: 採用
- 実装: `fxsim/markets/components/extreme.py`(`HolidayLiquidity` 登録名 `holidays`、`ExtremeEvents` 登録名 `extreme`)、
  `DynamicSpread` の `thin_mult` と `extreme_spread_mult`
- 親: M002(stylized v1)、M004(malicious v2)

## 仮説
実際の USDJPY には、統計的な性質(ボラの塊・裾の厚さ)の延長では説明しにくい「事件」がある。
2019-01-03 のフラッシュクラッシュ(数分で約 3.5% 下落し、数時間で大半が戻る)、2022・2024 年の為替介入
(円安の流れと逆へ数十分で 2〜3% 動き、数日〜数週で一部戻る)、2016 年の英国の国民投票のような一方向の急変。
これらは年末年始・早朝・ロールオーバーなど**流動性が薄いとき**に起きやすく、起きている間はスプレッドが大きく広がる。

- 逆指値は飛んだ先で約定するので、損切り幅よりはるかに大きく負ける(経路で約定するブローカーで再現できる)
- 頻度は年に 1 回未満なので、**単純な規則の素の優位性はほとんど変わらない**はず(変わるなら穴を作っている)
- 尖度(1 時間足)は 1 回の急変で何倍にも変わる

## 設計
- `holidays`(VOLATILITY 段): 12/24〜1/2、4/29〜5/5、米感謝祭(11 月第 4 木曜とその翌日)を薄商いにする。
  ボラ ×0.8、スプレッド ×2.5、異常な値動きの起きやすさ ×8。`ctx.meta["thin_mask"]` に残す
- `extreme`(POST_PATH 段、悪意の後): 回数は年あたりの期待値(ポアソン)。起きる時刻は、21〜1 時 UTC を 5 倍、薄商いを 8 倍に重み付け
  - フラッシュクラッシュ 0.25 回/年: 3〜10 分で 1.5〜5% を 4 段で落ちる(1 分の中で数十 pip 飛ぶ)。8 割は円高方向。
    0.5〜6 時間の時定数で 4〜8 割戻る。最初の間はスプレッド ×30
  - 為替介入 0.15 回/年: 直近 60 日の流れと逆へ、20〜90 分で 1.5〜3.5%。3〜15 日の時定数で 3〜7 割戻る。
    その後 2 日ほどボラが上乗せされる。スプレッド ×5
  - ショック 0.02 回/年: 1 分で 3〜10% 飛んで戻らない。スプレッド ×50
  - 戻りは指数の形だが、終わりの点でちょうど「戻らない分」に着くように補正し、段差を作らない
- 採点: 素の尖度(`kurt_h1`)は 1 回の急変で 20 → 70 になるので、両側 0.05% を切り詰めた尖度(`kurt_h1_trim`)で採点する。
  `max_h1_move_pct`、`big_h1_moves_per_year`(1 時間で 1% 以上)、`max_spread_pips` は記録だけ

旧版の再現: stylized v1 は `{"holidays": null, "extreme": null}`、malicious v2 も同じ。

## 測り方
```bash
python -m fxsim eval-market stylized --years 3 --seeds 1-6 --proposal M005
python -m fxsim eval-market malicious --years 10 --seeds 1-8 --proposal M005
python -m fxsim eval-market malicious --params '{"holidays": null, "extreme": null}' --label malicious_v2 --years 10 --seeds 1-8 --proposal M005
```
- 現実らしさが 80 以上のまま
- パネル戦略の素のシャープの絶対値の最大が、v2 から大きく増えない(目安 < 0.3 からの悪化が 0.1 以内)
- 異常な値動きが期待どおりの頻度で起き、スプレッドが広がる(`tests/test_extreme.py`)

## 結果
採点を切り詰めた尖度に変える前は、4.6% の急落が 1 回入っただけで stylized の現実らしさが 100 → 21 に落ちた(素の尖度 73)。
急変を外した stylized でも素の尖度は 16〜62 とばらつく(元から数本の足に振り回される指標だった)。

10 年 x 8 パターン、fair ブローカー(素のシャープ。括弧はパターン単位の損益の t):

| 戦略 | malicious v2(急変なし) | **malicious v3** |
|---|---|---|
| bollinger_reversion | +0.05 (−1.32) | +0.24 (−0.56) |
| donchian_breakout | −0.05 (−1.10) | −0.08 (−1.84) |
| ma_cross | −0.31 (−3.76) | −0.30 (−2.81) |
| simple_follower | −0.43 (−8.30) | −0.39 (−5.99) |
| random_entry | −0.06 (−3.72) | −0.07 (−3.84) |

| | v2 | v3 |
|---|---|---|
| 現実らしさ | 100 | 100 |
| 尖度 H1(切り詰め) | 8.5 | 9.0 |
| 1 時間で 1% 以上動いた足 / 年 | 6.0 | 6.2 |
| 異常な値動き / 年(8 パターン平均) | – | 急落 0.35、介入 0.14、ショック 0.03 |

stylized v2(3 年 x 6): 現実らしさ 100、尖度 H1(切り詰め)10.5。

## 判定
採用。現実らしさは保ったまま、素のシャープの最大(simple_follower −0.39、ma_cross −0.30)は v2 と同じ程度で、
急変が新しい穴を作っていない。急変の影響は、経路で約定するブローカーでの損切りの滑りとして、費用の側(E004)に出る。

## 次の一手
- 為替介入は「円安が進んだとき」に限って起こす(今は流れの向きだけを見る)。水準(例: 1 年で 15% 以上の円安)を条件に足す
- 急変の時刻の重みを、実データのティックから推定する(今は手で決めた 5 倍・8 倍)
- simple_follower が malicious で素のシャープ −0.4 前後と負け続ける(v2 から)。逆張りの穴になっていないか、10 年 x 16 で確かめる
