# M004 適応する悪意(malicious v2 / real_bridge_malicious v2)

- 種類: 市場モデル / 状態: 採用(v2)
- 実装: `CrowdSqueeze.chase_gain`、`FalseBreakout.adapt_gain`、`StopHunt.adapt_gain`(部品の既定は 0 = v1。v2 の値はモデル側で渡す)
- 親: M003

## 仮説
E001 で malicious v1 にはブレイクアウトの穴があった(10 年 x 8 で donchian の素の pip/年 +972、t = 5.4)。
部品を 1 つずつ外すと、勢いを作る部品(群衆の逆突き・ダマシの走り・ストップの連鎖)と、
戻りを作る部品(レンジの引き戻し・ダマシの罠)の綱引きで、大きさを手で合わせると期間ごとにどちらかへ傾く。
→ 大きさを合わせるのではなく、**悪意を「直近で勝っている側」に向ける**と、優位性が長続きしなくなる。

## 設計
- `crowd_squeeze.chase_gain`: 群衆が見ている順張り(24 時間 EMA からの乖離の向き)の損益を、半減期 10 日で測る。
  順張りが勝っているほど群衆は順張りに寄り(w → +1)、相場はそれを戻す。負けているほど逆張りに寄り、相場は走る
- `false_breakout.adapt_gain`: 直近の抜けの結末(走り = +1、罠 = −1)を半減期 20 回で覚え、走りが続いたほど罠を増やす
- `stop_hunt.adapt_gain`: 直近のヒゲの結末(戻り = +1、連鎖 = −1)を覚え、戻りが続いたほど連鎖を増やす

## 結果(10 年 x 8 パターン、素の pip/年、括弧はパターン単位の t)
| 戦略 | v1 | chase 2 | chase 2 + 適応 1 | **v2: chase 1 + 適応 1** |
|---|---|---|---|---|
| ma_cross | +523 (2.6) | −293 (−2.0) | −500 (−5.2) | −271 (−2.1) |
| donchian_breakout | +972 (5.4) | +308 (3.1) | −14 (−0.2) | +112 (0.8) |
| bollinger_reversion | +609 (2.8) | +152 (2.5) | +207 (1.9) | +355 (2.4) |
| random_entry | −75 (−1.7) | −97 (−1.7) | −133 (−1.8) | −82 (−1.5) |

- 最大 |t| は 5.4 → 2.4。完全な 0 ではない(わずかに日中の戻り寄り)。追従を強めると順張りが負けすぎ、弱めると戻る
- 現実らしさ(3 年 x 3)は v1 89.9 → v2 100

## real_bridge_malicious v2
日足の終値が実データに固定されるため、持続するずれを作る悪意(群衆の逆突き・ダマシ)はその日のうちに戻る動きに変わり、
逆張りが勝つ(bollinger +820、t = 7.4)。v2 ではそれらを外し、適応するストップ狩りだけにした。
悪意なしの real_bridge と比べた差(10 年 x 8): ma_cross +116 → −199、bollinger −124 → +94。
**判定の主役にはせず、ブローカーとストップ狩りへの耐性を見るストレス試験として使う。**
