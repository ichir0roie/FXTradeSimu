# R002 real_bridge / R003 real_bridge_malicious

- 種類: 市場モデル / 状態: 採用。疑い 1 件あり
- 実装: `fxsim/markets/models/real_based.py`、部品 `RealSkeleton(mode=replay)` + 足の中の合成 + `AnchorBridge`

## 仮説
実データの日足を骨格にし、足の中だけをランダムに合成すれば、「実際の相場の範囲で変動する相場」を何本でも作れる。
足の中の振れ幅は、骨格に固定しなかった場合の日次の分散が実データと同じになるよう自動で伸縮する(`calibrate_vol`)。

## 結果
- 現実らしさ 80.9 / 81.4(E001)。分散比 1.02 / 1.09、|r| の自己相関 0.23(ボラの塊あり)
- 骨格の終値は必ず一致する(tests/test_markets.py)
- **疑い**: H1 の逆張り(bollinger_reversion)が全パターンで勝つ(fair で中央値 +98 万円 / 10 年、8 本中 8 本プラス)。
  日足の終値に向けて足の中を引き寄せる補正(ブラウン橋)が、足の中に平均回帰を持ち込んでいる可能性が高い
