# R001 real(実データの再生)

- 種類: 市場モデル / 状態: 採用
- 実装: `fxsim/markets/models/real_based.py`(`real` v1)、部品 `RealReplay`
- データ: `data/real/usdjpy_d1_fred.csv`(FRED の USD/JPY 日次、終値のみ、パブリックドメイン)

## 仮説
実際の相場そのもの。シードで変わらないので、実験では 1 本だけ回す。

## 制約
- 同梱データは日足の終値だけ。1 時間足・5 分足の戦略は回せない(ジョブは「対象外」になる)。
  1 分足の CSV を `data/real/` に置き `{"source": {"path": "..."}}` で差し替えれば、細かい足の戦略も回る
- 日足の高値・安値が無いので、日足の損切りは終値でしか判定されない(甘め)

## 結果(E001、2016-11〜2026-10)
| 戦略 | fair | malicious ブローカー |
|---|---|---|
| buy_and_hold | +60.2 万円 | +56.5 万円 |
| donchian_d1 | +29.2 万円 | +21.9 万円 |
| ma_cross_d1 | +17.6 万円 | +8.2 万円 |
| bollinger_d1 | −0.1 万円 | −5.6 万円 |

1 本だけなので、有意かどうかは言えない。同じ期間の real_bridge / real_bootstrap と並べて読む(T001)。

## v2(E002 の途中で修正)
v1 は終値の 1 点だけで足を作っていたため、日足の始値 = 終値になり、戦略の注文が**翌日の終値**で約定していた(1 日遅れ)。
v2 は足 1 本を「始値(終値だけのデータでは前日の終値)→ 終値」の点で表す(OHLC があれば高値・安値の点も)。
買い持ちの損益は real と real_bridge で一致する(30 年で 65.4 万円 vs 65.4 万円)。
日足の戦略で real と real_bridge がまだずれるのは、FRED に米国の祝日が無い(real_bridge はその日も足を作る)ことと、
終値だけのデータには日中の高値・安値が無く損切りの判定が変わることによる。
