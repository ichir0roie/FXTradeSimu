# E063 発表の種類を問わず、跳ねた足の後に入る

- 種類: 実験 / 状態: 完了(2026-11-13)。全部の形が不合格
- 実装: `fxsim/research/spike_follow.py`
- 親: E062(米雇用統計だけ)、E060

## 問い
E062 は米雇用統計の日時だけで測った。ほかの発表(CPI・FOMC・各国の中銀・要人発言)でも同じか。発表の日時は手元に無く、
記憶から並べると間違いが入るので、暦の代わりに「足が平常の何倍も跳ねた」ことを足の終値で見つけ、その後に入る。

## 仮説
跳ねた後に続く(順張り)か戻る(逆張り)癖があれば、どちらかが費用を越える。E060 では 1 時間足の帯の外まで跳ねた値は戻らずに
走ったので、順張りが素の損益で勝つと考える。ただし費用(1 取引 1.5〜2 bp)を越えるかは分からない。

## 設計(回す前に決めた)
- 跳ねた足: 1 時間足 i の幅が、前の 480 本の幅の中央値の k 倍以上(k = 3・5)、実体が幅の半分以上、ロールオーバーの足ではない。
  次の跳ねは 24 本あける。入りは全部、足 i の終値の後
- 形: cont(跳ねた向きに成行)/ fade(逆向きに成行)、出口 1h・4h・24h・calm。cont_tp / fade_tp(幅の中央値の 1 倍で利確、
  逆指値なし、負けは calm か 5 日 = 利用者の最初の案を跳ねた後に入る形にしたもの)。pull(跳ねた向きに半分戻しの指値)・
  pull_against(跳ねた先の 1/4 先に逆向きの指値)
- 対照: 跳ねていない足(幅が中央値の 0.8〜1.2 倍)を同じ数だけでたらめに選び、同じ決まりを当てる
- 主要 10 ペアの 2010-10〜2018-10 を発見、2018-11〜を確認、クロス 18 本を初見として分けて出す。約定は E062 と同じ

```bash
python -m fxsim.research.spike_follow
```
