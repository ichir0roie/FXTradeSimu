# E068 研究で使っている費用は本当か。どこを下げれば勝つ形が出るか

- 種類: 実験 / 状態: 完了(2026-11-13)。費用の見積もりはほぼ本当。安いペアに絞っても、日中の形は t 2 に届かない
- 実装: `fxsim/research/cost_reality.py`
- 親: E060・E062・E063(負けの大半が費用に見えた)、E040(デモ口座の約定の費用)

## 問い
利用者の問い(2026-11-13): 日中の形はどれも「素の損益は少しプラス、費用 1 取引 1.3 bp で負け」になる。そんなに費用がかかるのは事実か。

## 設計
- 研究の約定の費用: スプレッド(足の記録 = 足の中の最小)+ 成行の滑り 0.1 pip + 逆指値の滑り 0.3 pip
- fills: デモ口座の常駐(B056、USDJPY、E040)の成行の新規の約定値を、同じ分の 1 分足の bid と比べる(買いなら払ったスプレッド)
- spreads: ペア x 年ごとの記録のスプレッド
- cheap: 費用の安いペアに絞り、滑りあり / 0 で、E060 の裏返し(4 時間足の順張り、時間で出る)を回す。2020 年以降の結果を見て
  ペアを選んだので、2010-10〜2019-12 を選ぶのに使っていない期間として並べる。区切りは UTC 0 時と 2 時の 2 通りを合わせる

```bash
python -m fxsim.research.cost_reality fills
python -m fxsim.research.cost_reality spreads
python -m fxsim.research.cost_reality cheap
```

## 判定
- 費用の見積もりはほぼ本当(USDJPY のスプレッドは記録より 0.07 pip 広いくらい、成行の滑りは 0)。ただ「1 取引 1.3 bp」は、高いペアと
  2010〜2015 年の広いスプレッドと、確かめていない逆指値の滑り 0.3 pip を含んだ値で、安いペアの今の費用は 0.3〜0.6 bp
- 費用を最安にしても、日中の形の素の損益(1 取引 0.4〜1.5 bp)は小さく、有意な勝ちにはならない。負けの原因は費用だけではなく、
  1 時間〜1 日の値動きに対して取れる偏りが小さいこと
- 候補として残すのは USDJPY の 4 時間足の順張り(帯の外の逆指値、3 本で出る)だけ。両方の期間でプラスだが単独では有意でない
