# E059 株価指数の積立: 1 倍・NISA(S050)と 2 倍型・課税口座(S051)を、費用と税込みで比べる

- 種類: 実験 / 状態: 完了(2026-11-13)
- 実装: `fxsim/research/leveraged_index.py`、テスト `tests/test_leveraged_index.py`
- 親: S050、S051

## 問い
利用者の問い(2026-11-13): 2 倍型で、費用と税金を比べた場合、NISA の枠と比べてどのくらい違うか。
FX の値動きには期待値が無い(INSIGHTS)が、株価指数にはある。そこにレバレッジを掛けると、税と費用の後でどれだけ得か。

## 設計
- 毎月 3 万円 x 20 年(払った額 720 万円)。最後に全部売った後の手取りで比べる
- 指数: 算術の期待リターン 年 9%、ボラ 年 18%(米国株の過去の水準の目安)。月次の乱数は正規分布、裾の重い版は t 分布(自由度 4、分散 1 にそろえる)
- 借りた分の金利(先物に入っている米ドルの短期金利): 2% と 4%
- 信託報酬: 1 倍 0.1%、2 倍型 0.9%。税: 課税口座は利益の 20.315%、NISA は 0(枠を越えた分は課税口座)
- 2 万経路、シード 0。二つの案には同じ乱数を使う(共通乱数)
- 実データは使っていない。円とドルの為替・売買の差・先物のずれ・制度の変更は入れていない

```bash
python -m fxsim.research.leveraged_index               # 正規分布、金利 2% と 4%
python -m fxsim.research.leveraged_index --df 4        # 裾の重い t 分布
```

## 結果

### 正規分布

| 金利 | 案 | 手取り 下から 10% | 中央値 | 上から 10% | 元本割れ | 税の中央値 | 基準価額の最大 DD 中央値 / 悪い側 10% |
|---|---|---:|---:|---:|---:|---:|---:|
| 2% | S050 1 倍・NISA | 857 万円 | 1,680 万円 | 3,514 万円 | 5% | 0 万円 | 40% / 56% |
| 2% | S051 2 倍型・課税口座 | 584 万円 | 1,873 万円 | 8,271 万円 | 14% | 294 万円 | 71% / 88% |
| 4% | S050 1 倍・NISA | 857 万円 | 1,680 万円 | 3,514 万円 | 5% | 0 万円 | 40% / 56% |
| 4% | S051 2 倍型・課税口座 | 483 万円 | 1,494 万円 | 6,222 万円 | 20% | 197 万円 | 73% / 90% |

S051 の手取りが S050 を上回る経路: 金利 2% で 59%、4% で 40%。
参考: 1 倍を課税口座で持つと、中央値 1,485 万円(NISA との差 −195 万円)。

### 裾の重い t 分布(自由度 4)
中央値・下から 10%・元本割れ・最大 DD は正規分布とほぼ同じ(金利 2%: S050 1,685 万円 / S051 1,883 万円、上回る経路 60%。
金利 4%: 1,685 万円 / 1,499 万円、40%)。月次の乱数を独立に引く限り、20 年積み上げると正規分布に近づくため。
平均は数本の極端な経路で大きく振れる(S051 の平均 3,872 → 6,829 万円)ので、判断には使わない。

## 判定
1. NISA の非課税は確実に効く。1 倍どうしで中央値 +195 万円(税の分)
2. 2 倍型・課税口座が NISA の 1 倍に勝つかは、借りる金利で決まる。2% なら中央値 +193 万円(59% の経路で上)、
   4% なら −186 万円(40%)。ケリーの倍率(2% で約 2.2 倍、4% で約 1.5 倍)と合う
3. 下振れはどちらの金利でもはっきり悪い。下から 10% は 857 万円 → 483〜584 万円、元本割れ 5% → 14〜20%、
   基準価額の最大 DD は中央値で 40% → 71〜73%
4. 平均と上振れは 2 倍型が大きく上(上から 10% で 2〜2.4 倍)。期待値の大きさではなく、分布の右の裾を買う案
5. 今の米ドルの金利(4% 前後)の下では、全部を 2 倍型・課税口座にする根拠は無い。まず NISA を 1 倍で埋めるのが先
