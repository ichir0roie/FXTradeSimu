# E064 日時だけを入力にしたモデル(「日時で AI に判断させる」の実装)

- 種類: 実験 / 状態: 完了(2026-11-13)。当てる力はあるが、費用を越えない
- 実装: `fxsim/research/datetime_model.py`
- 親: E061(LLM に日付を渡す形は未来が漏れる)、E015(時間帯の癖は費用を越えない)

## 問い
利用者の案(2026-11-13)「日時で AI に判断させる」を、未来が漏れない形で実装する。LLM は過去の相場を学習しているので使わず、
日時から事前に分かる特徴だけを入力にしたモデルを、過去だけで学習して翌年を予測する(ウォークフォワード)。

## 仮説
時間帯・曜日・月末の癖は小さく存在する(E015・E061)。モデルにすると、それをまとめて当てられるが、1 時間の値動きの大きさに対して
費用(1 取引 0.6〜1 bp)が大きく、費用込みでは越えない。

## 設計(回す前に決めた)
- 相場: 相場の DB の 1 時間足 2010-10〜2026-11、主要 10 ペア。予測するのは、その 1 時間足の始値 → 終値(bid、bp)
- 特徴: UTC の時、ニューヨーク・ロンドンの現地時刻の時(夏時間を反映)、曜日、日付、月末までの営業日数、五十日、月
- モデル: lgbm(LightGBM の回帰、ペアごと、木 200 本・葉 15・葉の最小 300)/ cells((ニューヨークの時 x 曜日)ごとの過去の平均を、
  数の少ないマスは 0 に縮めたもの)。どちらも事前に決めた値で、調整していない
- ウォークフォワード: 2013〜2026 年の各年を、その年より前の全部で学習して予測
- 売買: 予測の絶対値が費用(学習期間のスプレッドの中央値 + 往復の滑り 0.2 pip)を越える足だけ、予測の向きに始値で入り終値で出る
- ロールオーバーの時間(20〜22 時 UTC)は学習にも売買にも使わない(E015 の作り物)
- 「向きだけ」は、全部の足で予測の向きに張ったときの素の損益(当てる力そのもの)

```bash
python -m fxsim.research.datetime_model
```

- 当てる力は本物: 学習に使っていない年で、lgbm は 1 足あたり素の +0.12 bp(10 ペアで t 4.95、10 ペア全部プラス)、cells でも
  +0.08 bp(t 3.55)。時刻の癖(時間帯・曜日)は実在する
- 大きさは費用の 1/5〜1/10。費用を越えると予測した足だけに絞っても、1 取引の素の損益は +0.37 bp(lgbm)で費用に届かず、
  費用込みは −0.43 bp(t −5.55)。14 年中プラスの年は、ペアごとに 1〜6 年
- cells の GBPJPY だけ費用込み +0.55 bp(t 1.26、年 81 回)。10 ペア x 2 モデルから 1 つ当たっただけと区別できない

## 判定
却下。日時から当てる力はあるが、1 時間の売買では費用の 1/5〜1/10 にしかならない。E015 の結論(時間帯の癖は本物でも費用を越えない)を、
学習するモデルで確かめ直した形。LLM に日付やニュースを渡す形は、この場ではバックテストできない(E061)。
