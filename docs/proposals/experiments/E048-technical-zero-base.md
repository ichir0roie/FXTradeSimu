# E048 テクニカルをゼロから探し直す: 日足の 184 型のふるい、理論どおりの実装との比較、押し目の検証

- 種類: 実験 / 状態: 完了(2026-11-13)
- 実装: `fxsim/research/ta_scan.py`(ふるい、約 50 秒)、`fxsim/research/ta_theory.py`(今の実装と理論どおりの使い方)、
  `fxsim/research/pullback_fill_hour.py`(約定の時刻)、戦略 S048 `main_pullback_d1`、`main_trend_free` の signal = pullback
- 動作ケース: B060(押し目、両方向)、B061(受け取る向きだけ)、B062・B063(10 ペアの口座版)
- 親: E046(両方向の順張りは全滅)、E011(基本検証の 44 本は全部不合格)

## 問い
利用者の依頼(2026-11-13): テクニカル分析でテストを合格する型を探し続ける。これまでの評価は最新の対策とコードで
やっていないので、ゼロからやり直してよい。手法の使い方が悪い(実装が理論とずれている)のではないかも調べる。

## 設計(回す前に決めた)
- ふるい: 主要 10 ペアの日足の実データ(相場の DB)。建玉は足の終値で決め、翌日の値動きを取る。「値動き − 費用」
  (往復 0.03%)で見て、スワップは入れない。発見(1996〜2013)と確認(2014〜2026)の両方でプラスのものだけを候補にする。
  t はペアを足してから月ごと。ふるいは合否ではない(判定は verify と pair-eval)
- 候補は教科書の数字のまま戦略にして(結果を見て数字を選ばない)、最新の対策(コストゲート・固定比率の量・終値の損切り・
  口座の床)を入れた本命の枠で verify と pair-eval にかける
- 理論との比較: 指標の計算(`strategies/indicators.py`)と基本検証の戦略を読み、理論と違う点を理論どおりにした版を同じ単位で測る

## 結果

### 1 ふるい(184 型 + 合成クロス 28 組 x 6 通り)
順張り(チャネル抜け・EMA・モメンタム・MACD・ADX)、短期の逆張り(z・RSI・ストキャス・ボリンジャー)、ローソク足
(包み足・ピンバー・はらみ足・アウトサイド・NR7・キーリバーサル・抜けの失敗・連続陽線)、押し目、52 週の位置、ボラの局面、
曜日、通貨の強弱(8 通貨)、合成クロスの平均回帰。

- 発見と確認の両方で t ≥ 2 の型は 0 本。両方でプラスだったのは 11 本で、上位は全部「長いトレンドの向きへの押し目」
  (rsi3 pullback sma200: 全期間 +5.67% / 年・t 1.74、10 ペア中 9 ペアでプラス。rsi2 版 +4.08%・t 1.59)
- 2014 年を境に相場の性質が反転している。順張り(mom 252・donchian 200/100・mom63)は発見でプラス・確認でマイナス、
  逆張り(rsi14 の逆張り 確認 t +3.00、合成クロスの平均回帰 確認 t +1.5〜2.0)は発見でマイナス・確認でプラス。
  片方の期間だけで選んだ型は、もう片方で逆に出る
- 通貨の強弱の 1 日の逆張りは素の損益が年 +17%(6 建玉)あるが、年 1,056 回の取引で費用が 32%。回転で消える
- 曜日・ローソク足・NR7・抜けの失敗は、素の損益がほぼ 0 で費用の分だけマイナス

### 2 今の実装と理論どおりの使い方(`ta_theory`、年率 %、A = 発見・B = 確認)
指標の計算(RSI・ATR・ADX はワイルダーの平滑、SAR、一目の先行スパンのずらし)に誤りは無かった。使い方の違いは次のとおり。

## 判定
1. テクニカルで verify を全部通ったのは B060(押し目、両方向)。ただし採用の候補にはしない。pair-eval は不合格、
   Deflated Sharpe 0.10、族としての t は 1 前後、費用を引いた 1 取引の差し引きは 2010〜26 年で t 1 未満。B045 と同じ位置づけ
   (USDJPY の 30 年では合格、10 ペアでは費用と同じ大きさ)
2. 手法の実装が理論とずれていることは、負けの原因ではなかった。理論どおりにしても結果は変わらない
3. 日足のテクニカルが両方の期間で残らない理由は、2014 年前後での性質の反転(順張りが効く相場 → 逆張りが効く相場)。
   どちらかに決めた型は、片方の期間で負ける。両方で残ったのは「長い向きには順張り・短い行き過ぎには逆張り」を重ねた押し目だけ
4. verify の C1・C5 の読み方に注意が要る。並べ替えは同じ 30 年の標本から作るので、パターン単位の t は実データの時系列の t の
   およそ √(パターン数) 倍になる(n = 10 の t 5.68 は、時系列の t 約 1.8 に相当)。C1 の「t ≥ 2」は時系列の t 0.63 でも通る。
   短い期間で手仕舞う型ほど並べ替えで損益が変わらないので、この見かけが大きい

## 次の一手

  するかを決める(利用者の判断。基準を変えると B045・B049 系の判定も付け直しになる)
- 押し目は、費用を下げる入り方(押した先に指値を置く)なら素の +3.5〜8.6 pip が残るかを、1 時間足の高安で約定を判定して測る

- 五十日の仲値は、5 分足が 3 年分たまってから測り直す
