# E002 ひとつのモデルの長期検証

- 種類: 実験 / 状態: 実行済み
- 実装: `fxsim/verification.py`、`fxsim verify`、画面 `/cases/V-<動作ケース>`

## 目的
「ひとつのモデルが長期的に利益を出すか」を、1 本のバックテストの運ではなく、数字で判定できるようにする。

## 方法
同じ期間・同じシードの相場パターンの組で、モデルと **方向だけでたらめ版**(`direction_null`: 同じシグナル・同じ損切りの規則で、
建てるたびに買い/売りを乱数で決める)を対にして回す。

| 組 | 市場 | 使い方 |
|---|---|---|
| 実データ | real(v2: 終値だけの日足は始値 = 前日の終値で約定) | C1 の条件の一つ |
| 並べ替え(独立) | real_bootstrap(実データのリターンをブロック単位で並べ替え) | **有意性の判定の主役** |
| 実データ + 日中ランダム | real_bridge | 参考(日足の戦略では実データのコピーになり、独立な証拠にならない) |
| 偽薬 | real_bridge_placebo(符号でたらめ) | C3 |
| 完全ランダム / ストレス | stylized・malicious / real_bridge_malicious | 参考 |

判定: C1 利益(並べ替えで中央値 > 0、プラス ≥ 60%、t ≥ 2、かつ実データ 1 本 > 0)/ C2 方向でたらめ版より上(対の差の t ≥ 2)/
C3 偽薬より上(ウェルチの t ≥ 2)/ C4 年ごとの安定性。全部 → 合格、C1 と C2 → 条件付き、それ以外 → 不合格。

## 作っている途中で見つけて直した落とし穴
1. **擬似反復**: 日足の戦略にとって real_bridge は実データ 1 本のコピー。これで t を取ると t = 22 のような偽の有意が出る。
   独立な real_bootstrap で測るように直した(同じモデルで t = 1.3)
2. **並べ替えのブロック長**: 20 日ブロックは、それより長い構造(60〜120 日のトレンド)を壊す。`--block-days` を戦略の見る期間より長くする
3. **再生の約定の遅れ**: 終値しか無い日足の再生で、注文が翌日の終値で約定していた(1 日遅れ)。始値 = 前日の終値の点を足した(real v2)
4. **陽性対照**: 本物の優位性(日次リターンの自己相関 0.3)を仕込んだデータと、それに乗る戦略なら **合格** になることをテストで確認
   (`tests/test_cases.py::test_verification_passes_a_model_with_a_real_edge`)。偽薬ではその優位性が消える(t < 2)

## 結果(30 年 = 1996-11〜2026-10、10 パターン、並べ替え 250 日ブロック、malicious ブローカー)
結果の表は `python -m fxsim cases show V-B004` / `V-B007`、画面は `/cases/V-B004` / `/cases/V-B007`。

| モデル | 実データ 1 本 | 並べ替えの中央値 / t | 判定 |
|---|---|---|---|
| B004 日足 EMA 交差 | (DB の V-B004 を参照) | (同) | 不合格 |
| B007 時系列モメンタム | −23 万円 | +8 万円 / 0.30 | 不合格 |

B004 は 20 日ブロックでの試行で、**実データ 1 本では +42 万円なのに並べ替えでは中央値 −86 万円(プラス 20%)**だった。
1 本のバックテストだけなら「勝てるモデル」に見えるが、ありえた別の歴史では負ける。この検証が見抜きたかったのはこれ。

## 結論
仕組みは、運と優位性を区別できる(陽性対照は合格、偶然の勝ちは不合格)。
今ある単純な日足モデルで、USDJPY の 30 年にコスト込みで長期的な利益を示せたものは無い。
