# E016 実データだけで、主要 10 ペア x 期間に分けて全 45 本を評価し直す

- 種類: 実験 / 状態: 完了(2026-11-11)。合格 0 本
- 実装: `fxsim/pair_eval.py`(`python -m fxsim pair-eval --all`)、市場モデル `real_pair`(R012)
- 材料: 相場の DB(OANDA-Japan MT5 Demo、`configs/market_data/oanda-demo-majors.yaml`)の 10 ペア
  (USDJPY・EURUSD・GBPUSD・AUDUSD・NZDUSD・USDCHF・USDCAD・EURJPY・GBPJPY・AUDJPY)の日足(1993〜)・1 時間足(2010〜)・5 分足(2025-07〜)。
  複数ペアの戦略だけは FRED の対円 7 ペアの日足(basket_real)
- 親: E011(全 44 本の 30 年の検証、合成の相場が中心)、S038(B045)、E015

## 問い
合成の相場(並べ替え・偽薬・完全ランダム)は、実際の為替の癖を再現しきれない(S038 で B045 の勝ちは実データ系にだけ出た)。
では、合成を使わず、手元の実データだけを「通貨ペア x 期間(レンジ)」に切ってパターンを増やしたら、全戦略の評価はどうなるか。

## 設計
動作ケースごとに、足の長さで実データと期間を決め、ペア x 期間の全パターンで、動作ケースと方向でたらめ版(検証と同じ帰無)を対で回す。
ブローカー・量・取引時間は動作ケースのまま(多くは malicious、1 万通貨)。

| 戦略の足 | 実データ | 期間(レンジ) | パターン |
|---|---|---|---|
| 日足 | 相場の DB の日足 10 ペア | 1996〜2001・2002〜07・2008〜13・2014〜19・2020〜2026-11(6 年ずつ 5 つ) | 50 |
| 4 時間足・1 時間足 | 相場の DB の 1 時間足 10 ペア | 2010-11 から 4 年ずつ 4 つ(〜2026-11) | 40 |
| 15 分足・5 分足 | 相場の DB の 5 分足 10 ペア | 2025-07-14 から約 4 か月ずつ 4 つ(〜2026-11) | 40 |
| 複数ペア(B011〜B015) | FRED の対円 7 ペアの日足 | 1999〜2004・2005〜10・2011〜16・2017〜21・2022〜2026-11 | 5 |

1 ペアの相場は `real_pair`(R012): 決済通貨を期間の最初の円換算で円に直し、記録のスプレッド(年代ごとの実際の幅。
1990 年代の USDJPY・EURUSD は 3〜5 pip、今は 0.4〜0.5 pip)、足の中は MT5 のテスターと同じ順番で連続、スワップはペアの金利差。
実データなので、金利差と値動きのつながり(高金利通貨の値下がり)はそのまま残る(合成の相場の検証の穴、ROADMAP の「合成の相場のスワップ」が無い)。

### 判定(回す前に決めた基準)
| 条件 | 中身 |
|---|---|
| R1 利益 | パターンの損益の中央値 > 0、プラスの割合 ≥ 60%、t ≥ 2 |
| R2 帰無より上 | 同じパターンでの差(動作ケース − 方向でたらめ版)の t ≥ 2 |
| R3 期間の安定 | 期間ごとの平均(全ペア)がプラスの期間が 75% 以上 |
| R4 ペアの広がり | ペアごとの平均(全期間)がプラスのペアが 60% 以上(複数ペアの戦略は対象外) |
| R5 スワップを除いて | スワップを除いた損益で R1 と同じ基準 |

合格 = 全部 / 有望 = R1・R2・R5 / それ以外 = 不合格。同じ期間のペアどうしは相関するので、パターン単位の t は証拠を大きく見せる。

```bash
python -m fxsim fetch-mt5 configs/market_data/oanda-demo-majors.yaml --timeframes D1 --bars 8000   # ペアごとに遡れる本数が違う

python -m fxsim pair-eval B045                  # 1 本の詳細(期間ごと・ペアごとの平均)
python -m fxsim pair-eval --all --rejudge       # 回し直さずに判定だけ
```

## 途中で直したもの(評価の前に)
1. 実データの足の中の損切りの約定: エンジンは足の中の点が 10 個以下だと「1 歩の大きさが測れない」として、損切りを越えた点
   (足の安値・高値の端)で約定させていた(日足の再生向けの悲観的な決まり)。実データの 4 点(始値・安値・高値・終値)では
   高値・安値が足の端なので、足の中は連続して動いている。損切り・利確は水準の価格で約定し、飛び(窓)は始値の点へ動いたときだけにした
   (`Bars.points_per_bar` / `open_steps`、1 ペアのエンジンと MT5 のテスターの両方。合成の相場は変わらない)。
   直す前は random_entry(1 時間足、malicious)の費用が 1 取引 9.1 pip、直した後は 2.1 pip(E012 の 1.7〜2.9 pip と合う)
2. 記録のスプレッドの広げ方: 前後の足の最大を足の 4 点全部に当てると、ロールオーバーの前の 1 時間まるごとが 2〜3 pip になり、
   方向でたらめでも損切りが刺さって素の損益が −2.6 pip / 取引になった。広げるのを足の境目の点(始値・終値)だけにして、
   方向でたらめの素の損益が 0 に戻った(fair、5 本 x 12 年で USDJPY −0.36 ± 0.38、EURUSD +0.30 ± 0.29)

## 判定
実データだけ・10 ペア x 期間でも、合格する戦略は無い。合成の相場の評価と食い違ったのは本命の B045 で、USDJPY 1 本の 30 年(S038)では
合格したが、10 ペアには広がらなかった。合成で負けて実データで残ったのは B008 のキャリーだけで、その中身は金利差。

## 限界
- 円への換算は期間の最初の値で固定(期間の中の円高・円安で、ドル建ての損益の円の値はずれる。符号と pip は正しい)
- 日足の約定は日足の始値(ロールオーバーの直後)だが、その点のスプレッドは前日と当日の記録(足の中の最小)の大きい方。実際はもっと広いことがある
- 5 分足は 1.3 年しかない(4 期間 x 4 か月)。1 時間足の期間は 4 年 x 4
- 複数ペアの戦略は 5 パターンしかない(FRED の 7 ペア、1999〜)
- ブローカーは動作ケースのまま(多くは malicious)。費用の軽い口座での成績は別に見る必要がある
