# E055 日足未満のテクニカルを、発見と確認を分けて探し直す

- 種類: 実験 / 状態: 完了(2026-11-13)。発見で基準に届いた型は 0。確認には進まない。「設計」の節はコミット 584f2f4 で結果の前に固定した
- 実装: `fxsim/research/intraday_limit.py` の `family_signals`(7 つの型)、`fxsim/research/intraday_search.py`
- 親: E052〜E054(同じデータを見ながら型を絞ったので、初見のデータで合格しなかった)

## 問い
利用者の目標: 日足未満のデイトレードで、テクニカルの手法だけで、機械で回して勝つ戦略を見つける。
E052〜E054 の反省から、発見に使うデータと確かめるデータを先に分け、選ぶ基準と合格の基準を回す前に決める。

## 設計(回す前に決めた。結果を見て変えない)
- 型 7 つ(`family_signals`): pullback / momentum / breakout / breakout_trend / fade_z / bb_reentry / ema_cross
- 足 4 つ: 1・2・4・8 時間(毎時判断。区切りをずらした全部の位相をまとめる)
- 荒さ 3 つ: 絞らない / ATR(20) / ATR(250) ≥ 1.2 / < 0.8
- 入り 2 つ: 成行 / 指値 ATR x 0.5(その足 1 本ぶん有効)
- 出: 型ごとの出の信号か 6 本、損切り ATR x 3。数字は全部ここに書いたまま(長い向きは 200 本平均、RSI(2) の水準は 10)
- 合わせて 7 x 4 x 3 x 2 = 168 通り。約定は E052 と同じ(1 時間足の bid の高安とスプレッド、不利な側に倒す)
- 発見: 主要 10 ペア、信号が 2010-10〜2018-10-31 のものだけ
- 選ぶ基準: 発見で 1 取引の損益(費用の後)> 0 かつ月ごとの t ≥ 3.5(168 通りで割り引いた水準。両側 5% のボンフェローニで t 3.6 ほど)
- 確認(選んだものだけ、1 回だけ): 全 28 ペア(主要 10 + クロス 18)、信号が 2018-11-01〜2026-11-10 のもの。
  合格は 1 取引の損益 > 0・月ごとの t ≥ 2・プラスのペア 60% 以上・でたらめな入り 6 通りとの差 z ≥ 2 をすべて満たすこと
- pullback は E052〜E054 で 2010〜2026 年の主要 10 ペアとクロスを見ているので、選ばれても確認は汚れている。
  pullback の結果は参考に回し、合否の主張には使わない
- 確認を通った型があれば、エンジンで実装して pair-eval(2018-11〜の 2 期間 x 28 ペア)を最後の関門にする

## 判定
1. 発見と確認を分けて、基準を先に決めて探すと、日足未満のテクニカルで費用の後に勝つ型は見つからなかった(168 通り中 0)
2. E052〜E054 と合わせると、日足未満で残った手がかりは「荒い時期に指値で待って入ると、費用の後でも少しプラスになる」だけで、
   それは型(どの手法の信号か)にほとんど依らない。公式の基準で「勝つ戦略」と言える大きさ・確かさには、どの試験でも届いていない
3. 過去のデータでの探索はここで打ち止めにする。これ以上は、試した数が増えるだけで証拠は増えない
