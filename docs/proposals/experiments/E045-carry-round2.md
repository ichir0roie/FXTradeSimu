# E045 スワップ狙いの 2 本(B049・B059)に 4 つの案を足して比べる: 利確の指値・逆指値の距離・ボラで量・半分ずつ

- 種類: 実験 / 状態: 完了(2026-11-13)
- 実装: `fxsim/research/carry_round2.py`(約 2 分)、`main_carry_breakout` の `vol_target`(既定は使わない)
- 親: E044(B059)、E042(損切りの幅)、E041(利確の指値)、E039(DD は量で決める)

## 問い
利用者の方針(2026-11-13): どんどん比較して、使えそうな戦略を探す。E042〜E044 の「次の一手」に残った案を、同じ物差しでまとめて比べる。

## 設計(回す前に決めた)
- A: B059 に利確の指値(建値 ± 建てた足の ATR x 2)。入り直す・入り直さない(B057 と同じ形)
- B: 急変用の逆指値を ATR x 9 → x 5・x 3(E042 では ATR x 3 で刺さるのは取引の 7%、成績は損切りなしと同じ)
- C: ボラで量を決める。ATR / 終値が 0.7% のペアで 2,000 通貨、振れの大きいペアは減らす(1,000 通貨刻み、1,000〜4,000)
- D: B049 と B059 を半分ずつ(5 万円・1 ペア 1,000 通貨の口座を 2 つ回して、有効証拠金を足す)
- 相場・口座・点数は E026 と同じ。13 通りから拾うので、点数の差 0.1 未満はノイズ(E031)。見るのは、4 つの相場の組
  (直近の実データ・ランダム・古い実データ・古いランダム)で同じ向きにそろうか

## 判定
1. 13 通りの点数は +0.49〜+0.65 で、B049(+0.58)とノイズの幅の中。どれも「はっきり良い」とは言えない
2. D(B049 と B059 を半分ずつ)だけ、4 つの相場の組すべてで B049 と同じか良い: シャープ +0.63 / +0.63 / +0.67 / +0.64
   (B049 は +0.60 / +0.56 / +0.65 / +0.68)、最大 DD は 18%・28%(最悪 45%)・19%・25%(最悪 52%)で、どの組でも B049 以下。
   年率 ÷ 最大 DD は 0.40 で一番(B049 0.36)。入りの決まりが違う 2 本は負ける時期が少しずれる。差は小さい(ランダム 24 本で
   B049 以上は 14〜15 本)が、仕組みを増やさず量を分けるだけで得られる
3. B(逆指値 ATR x 3)は B049 では少し良い(最悪の DD 49% → 44%、55% → 49%、B049 以上 16〜17 / 24 本)。B059 では変わらないか
   少し悪い(古いランダムの最悪 60% → 71%)。EMA 版は建値から離れて持つ時間が長く、近い逆指値が刺さりやすい。ATR x 5 は
   どちらもほぼ同じ。ATR x 9 のままにする
4. A(B059 + 利確の指値)は成績を変えない(点数 +0.61〜+0.64)。取引は年 4 → 10 回に増える。常駐で利確の指値を置く決まり
   (E041)を守るなら、入り直す版を使える
5. C(ボラで量)は採らない。ランダムの最大 DD は下がる(31% → 24%)が、直近の実データが悪い(B049 シャープ +0.60 → +0.38)。
   振れの大きいペア(円のペア)が直近の稼ぎ頭で、そこを減らした。相場の組で向きがそろわない
6. pair-eval は B049・B059 とも不合格。金利差が小さい 2008〜2019 年は、どちらも稼げない(INSIGHTS 16 と同じ)
