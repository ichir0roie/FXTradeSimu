# E001 基本戦略の長期シミュレーション

- 種類: 実験 / 状態: 実行済み
- 設定: `configs/long_run_baseline.yaml`(10 年、ランダム相場 6 種 x 8 パターン + 実データ 1 本、ブローカー 2 種、戦略 9 本 = 882 本)
- run: #1(`python -m fxsim report 1 --patterns`、画面 `/runs/1`)。4 コアで約 105 秒
- 再現性: 同じ設定で 3 回作り直し、損益は 1 円単位まで一致

## 結果の要点
1. **コストと悪意は確実に効く**: random_entry は malicious ブローカーで 48 パターン全部マイナス(t = −17.4)
2. **malicious 市場の穴**: donchian_breakout(H1)が malicious 市場でだけ大きく勝つ(fair で中央値 +109 万円 / 10 年)→ M003 / M004
3. **実データ系の穴の疑い**: 日足の骨格に橋渡しした市場では、H1 の逆張りが勝ちすぎる → R002 / R005
4. 実データ 1 本の日足戦略は donchian_d1 +21.9 万円、ma_cross_d1 +8.2 万円、bollinger_d1 −5.6 万円(malicious ブローカー)。
   1 本なので判定しない
