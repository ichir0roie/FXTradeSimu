# E035 負けどころを避けると、短期の順張りはどうなるか(USDJPY の実データ、時間足ごとに 1 本)

- 種類: 実験 / 状態: 完了(2026-11-11)。1 本の歴史での整理で、1 時間足の候補は他のペアで未確認
- 実装: `fxsim/research/loss_filters.py`(`python -m fxsim.research.loss_filters`)、
  フィルタ `fxsim/strategies/builtin/entry_filter.py`(S042、登録名 `entry_filter` v1)
- 親: E033(負けるタイミング)

## 問い
E033 で見つけた順張りの負けどころ(ロールオーバー・荒い局面・一方向の局面・金曜)を、規則で避けると成績はどう変わるか。
逆張りは対象から外す(利用者の判断)。

## 対策(回す前に決めた)
| 番号 | 対策 | 仕組み |
|---|---|---|
| 1 | ロールオーバー前後(日本時間 5:00〜8:59)は新規を出さない。持ち高は持ち越す | 取引時間(TradingSchedule、日本時間) |
| 1' | 同じ時間帯に入る足で持ち高をたたみ、新規も出さない | 取引時間の外は持たない(outside: close) |
| 4 | 荒い局面(ATR(14) / 直前 500 本の ATR の中央値 > 1.25)では新規を出さない | entry_filter(max_vol_ratio) |
| 5a | 一方向の局面(20 本の効率比 > 0.4)では新規を出さない(5 の切り分け用) | entry_filter(max_er) |
| 5b | スワップを受け取る向きだけ(USDJPY では買いだけ) | EngineConfig.swap_side_only(E022) |
| 6 | 金曜(日本時間。土曜の早朝 = NY の金曜を含む)は新規を出さない。持ち高は持ち越す | 取引時間(曜日) |
| 組み合わせ | 1' + 4 + 6、それに 5b を足したもの | |
| 1'+5b(後から) | 1' と 5b だけ。結果を見てから足した(4 は単独で悪く、6 は効かなかったため) | |

E033 の 2(逆張りの損切り)と 3(順張りのダマシ)は、入る時点で見分ける手掛かりが無いので対策を置かない。
対策の後に「3 本以内に終わった取引」「損切りで終わった取引」の割合が減るかだけを見る。

## 仮説
- H1 1 / 1' は 1 分〜15 分足の費用を大きく減らし、期待値を E033 の 1b(−0.2〜−0.4 pip)くらいまで戻す。プラスにはならない
  (素の損益が ±0.4 pip)。1 時間・4 時間ではほとんど変わらない
- H2 4 は 1 回の負けを小さくするが、順張りの大きな勝ちも荒い局面で出ている(E033: 15 分以上の荒い局面の期待値はプラス)ので、
  期待値はほとんど変わらないか悪くなる
- H3 6 は効かない。金曜の負けの集まり方は 1.01〜1.11 倍しかない。金曜が荒いかどうかも値動きの大きさで確かめる
- H4 5b は 16 年の 1 時間・4 時間で良く見えるが、その分は円安のドリフトとスワップ(戦略の手柄ではない)。
  一方向での順張りの負けは、向きではなく「動き切った後に入る」出遅れが原因で、入る前の伸びが大きい取引ほど悪い
- H5 対策は、方向でたらめ版にも同じだけ効く(向きを当てる力ではなく、費用の高い時間・状態を避けているだけ)

## 設計
- 相場・期間・手法・ブローカー・数量は E033 と同じ(1 分 = M1 の 3 か月、5 分・15 分 = M5 の 16 か月、1 時間・4 時間 = H1 の 16 年。
  順張り 8 本、OANDA、1 万通貨)
- 基準も対策と同じ書き方(日本時間の取引時間、曜日の制限なし)で回す。E033(UTC の月〜金)とは日曜の夜の扱いだけ違う
- どの版も方向でたらめ版に同じ対策を掛けて対で回す
- 5b のドリフト分: 期間の平均の値上がり x 持っていた時間 x 向き(pip)。スワップも pip に直して並べる
- t は週ごとの損益の合計で数える

### 対策ごとの読み
- 1 ロールオーバー(日本時間 5:00〜8:59)を避ける: 1 分〜15 分の費用が 2.25 / 1.50 / 1.22 → 0.42 / 0.43 / 0.46 pip。
  期待値は −2.14 → −0.33(1 分)、−1.57 → −0.23(5 分)、−1.00 → +0.18(15 分、たたむ版、週の t +0.4)。
  方向でたらめ版も同じだけ良くなる(−2.24 → −0.32 など)ので、向きを当てる力は増えていない。費用の高い時間を避けた分だけ
  - 1 分足では「3 本以内に終わる取引」が 45% → 27%、損切りが 45% → 28% に減る。1 分足のダマシと損切りの多くはロールオーバーで起きていた
  - たたむ版(1')は 4 時間足では悪い(+2.42 → −0.74)。毎日たたむので、順張りの勝ちの元になる長い保有が切れる。たたむのは短期だけにする
- 4 荒いときに入らない: どの足でも悪くなる(15 分 −1.00 → −1.74、1 時間 +0.38 → −0.00、4 時間 +2.42 → +1.18)。
  順張りの大きな勝ちも荒い局面で出ているので、負けと一緒に勝ちも捨てる
- 6 金曜に入らない: ほぼ変わらない(±0.3)。金曜の値動きは平均の 1.04〜1.16 倍で少し荒いが、木曜も 1.05〜1.10 倍。
  静かなのは火曜・水曜(0.86〜0.96 倍)
- 5a 一方向の局面で入らない: 変わらない(±0.1)
- 5b 買いだけ: 1 時間・4 時間で +1.62・+6.30(スワップを含まない。スワップは別に +0.80・+3.13)。円安のドリフト分
  (+1.19・+4.90)を引くと +0.43・+1.40 で、方向でたらめ版(−0.27・+3.24)と比べても大きくはない。大半はドリフトとスワップ。
  (訂正 2026-11-11: 初めの版はスワップを含まない期待値からさらにスワップを引いて −0.37・−1.73 と書いていた。二重に引いた誤り)
- 5b の中身は「買いだけ」ではなく「金利差が業者の取り分を越える時期だけ、受け取る向きに入る」。USDJPY では受け取れるのは常に買いで、
  1 時間足の 16 年の 45%(2009〜2015 年など)はどちらも受け取れず新規が出ない。方針として据え直したのが E036

### 一方向で順張りが負ける理由(基準の取引、3 の表)
- 原因は出遅れより向き。一方向の局面の買いは 1 時間 +2.95・4 時間 +7.14 pip、売りは −1.71・−6.32 pip。
  USDJPY のこの 16 年は、上への一方向は続き、下への一方向(円高の急変)は続かなかった
- 出遅れが効くのは、入る前の 20 本で 8 ATR 以上動いた後に入った取引だけ(1 時間 −18.7 pip、5 分 −7.1 pip)。ただし数が少ない(52〜283 本)

### 1 時間足の候補
- 1'+4+6+5b は 1 時間足で +3.12 pip / 取引(週の t +3.5、16 年で +320 万円 / 8 手法)、8 手法すべてプラス。
  方向でたらめ版も +1.80 なので、上乗せは約 1.3 pip。ドリフト分は 0.47 pip、スワップは 0(毎日たたむ)
- 4 は単独では悪いのに、買いだけと組むと良くなる(1'+5b の +1.76 → +3.12)。組み合わせを 10 通り試した中の一番で、
  USDJPY の円安の 16 年 1 本の結果。過剰適合を疑う

## 判定
- H1(1 / 1' は短い足の費用を大きく減らすが、プラスにはならない): 支持。1 分・5 分は −0.2〜−0.3 pip に縮むがマイナスのまま。
  15 分のたたむ版の +0.18 は方向でたらめ版も +0.13 で、手柄ではない
- H2(4 は効かないか悪くする): 支持。全部の足で悪くなる
- H3(6 は効かない): 支持。金曜は少し荒いが、木曜も同じくらい
- H4(5b は円安とスワップ。一方向での負けは出遅れ): 前半はおおむね支持(ドリフトを引いた残りは +0.4〜+1.4 pip)、後半は一部不支持(原因は向き。出遅れは 8 ATR 以上の伸びの後だけ)
- H5(対策は方向でたらめ版にも同じだけ効く): 1・1'・4・6・5a は支持。1 時間足の 1'+4+6+5b だけ約 1.3 pip の上乗せが残る(候補)
- 短期(1 分〜15 分)の順張りは、負けどころを避けても、費用を越える優位性は無い(E021・E033 と同じ結論)。
  対策で変わるのは負け方の速さで、1 分足の 8 手法の合計は 3 か月 −606 万円 → −122 万円(1 万通貨)
