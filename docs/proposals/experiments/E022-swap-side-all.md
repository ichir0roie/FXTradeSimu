# E022 全戦略を「スワップを受け取る向きだけ」にして、主要 10 ペアで評価し直す

- 種類: 実験 / 状態: 完了(2026-11-11)。合格 0 本
- 実装: `EngineConfig.swap_side_only`(1 ペアのエンジン・MT5 のテスター・複数ペアのエンジン)、
  `python -m fxsim pair-eval --all --broker oanda --daily-fill-hour 2 --swap-side`、
  `python -m fxsim.research.horizon_edge --swap-side`
- 親: E017(OANDA の条件、向きを絞らない)、E018(日足 5 本でのスワップのゲート)、E021(時間の長さ)

## 問い
「スワップがマイナスになる向きの取引はしない」を全部の戦略に掛けたら、各戦略は 10 ペアの実データでどうなるか。
時間の長さ(5 分〜半年)ごとには、どこから費用を越えるか。

## 設計
- エンジンの決まり `swap_side_only`: 新規の向きが、業者の取り分を引いたスワップの年率 > 0(受け取り)のときだけ出す。
  払う向きの新規は止め、逆向きの建玉があれば決済だけする。積み増し・決済・損切りは止めない。戦略のコードは触らず外から掛かり、
  方向でたらめ版にも同じだけ掛かる
- 相場とブローカー: E017 と同じ(real_pair の 10 ペア x 期間、OANDA、日足の約定は 2 時)
- 比べる相手: 向きを絞らない E017(日足は 2 時に約定した版)。B008・B046 はもともと受け取る向きだけなので、結果が同じになるのが正しい(確認になる)

## 読み取れること
1. 合格 0 本。B008・B046 は絞る前と同じ結果(もともと受け取る向きだけ)で、決まりの配線の確認にもなった
2. 日足の戦略は、絞るとほとんどがプラスになる(B004 平均 −5.4 → +7.6 万円 / 6 年、B007 −0.2 → +6.3、B010 −7.4 → +6.5、
   B035 +0.7 → +8.4、B033 −2.9 → +8.6)。中身はスワップ(平均 +5.6〜+9.8 万円)。ただし「方向でたらめ版に同じ決まりを掛けたもの」
   との差は、B010(t 3.31)を除いてゼロかマイナス(B004 −2.33、B007 −2.27)。良くなったのは決まり(キャリー)の手柄で、戦略の判断ではない(E018 と同じ)
3. 日中の戦略は、絞っても全部マイナスのまま。取引が 1/3 ほどに減って負けが小さくなるだけ(B001 −14.7 → −5.4 万円 / 4 年、
   スキャルピング −17.4 → −7.2 万円)。日中の持つ時間ではスワップの受け取りが 0.0〜0.2 pip / 取引しかなく、費用(1.1 pip)は変わらない
4. 時間の長さで見ると、受け取る向きだけの順張りは 2 日以上で差し引きがプラスになる(5 日 +4.6 pip、10 日 +10.7、半年 +102 / 取引)。
   ただし中身はスワップで、値動きの損益は長い時間ほどマイナス(63 日 −19 pip、126 日 −18 pip: 高金利通貨の値下がり)。差し引きの t は最大 1.7
5. 複数ペアの戦略は、通貨のモメンタム(B012)が −7.7 → +6.5 万円、7 ペアのトレンド(B014)が +3.2 → +11.7 万円になるが、5 パターンしかなく t は 1.0〜1.4

## 判定
「スワップを受け取る向きだけ」は、日足以上の戦略の負けをなくし、プラスにする。ただし勝ちの中身は金利差の受け取りで、
どの戦略の信号も、同じ決まりを掛けた方向でたらめ版より上ではない(B010 を除く)。日中の戦略には効かない。
採るなら、信号の凝った戦略ではなく、キャリーそのもの(B008・B046)を本命にし、信号は手仕舞い(保険)にだけ使うのが筋。
