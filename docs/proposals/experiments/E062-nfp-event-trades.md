# E062 指標発表(米雇用統計)を狙う売買

- 種類: 実験 / 状態: 完了(2026-11-13)。全部の形が不合格
- 実装: `fxsim/research/event_nfp.py`
- 親: E050(損切りと利確は期待値を作らない)、E060(帯の両側の指値)

## 問い
利用者の案(2026-11-13):
1. 世間の情報から大きく動く時期を狙い、片方の向きにだけ入る。一瞬跳ねたところで利確し、逆指値は置かない。
   負けたら相場が落ち着いてから閉じる
2. 発表をまたいで両方の向きに指値を置き、落ち着いたら両方を閉じる
3. (あたしの案)跳ねた後の戻りを、動いた向きに指値で拾う

## 仮説
- 発表の向きは予想との差で決まり、予想はもう値段に入っている。向きを当てる情報が無ければ、片側の入りは期待値 0 − 費用
- 利確を近くして負けを持ち続けると、勝率は上がるが平均は変わらず、損の分布が「小さく何度も勝って、たまに大きく負ける」形になる
- 発表の直後に戻る癖があれば 2 の指値が、続く癖があれば鏡の逆指値と 3 が勝つ

## 設計(回す前に決めた)
- 発表の日時は AI に選ばせず、BLS の決まりで作る: 対象月の 12 日を含む週(日〜土)の土曜の 20 日後の金曜、8:30 ニューヨーク。
  1 月 3 日以前なら 1 週後、7 月 4 日・3 日の金曜なら前の木曜。政府の閉鎖でずれた 2013-10・2013-11・2025-11・2025-12 は
  覚えている公表日に置き換え、2025-10 は除いた。選ぶのに相場は見ていない(ずれた回は「発表の無い時刻」が混ざるだけ)
- 確かめ: EURUSD の発表の足の幅の中央値は 41 bp、発表の無い金曜の同じ時刻は 19 bp。対照の中央値より狭い発表の足は 192 回中 12 回
- 相場: 相場の DB の 1 時間足 2010-10〜2026-11、対ドル 7 ペア。発表は足の真ん中(:30)。発表の足の始値 P0 を基準にする
- 物差し wv: そのペアの直前 12 回の発表の足の幅の中央値(因果的)
- A 片側・逆指値なし: 発表の 30 分前に成行。利確 k x wv(k 0.25・0.5・1.0・なし)。出口 calm(足の幅が直近 480 本の中央値以下に
  戻った最初の足)/ 4h / 24h / tp_or_5d(利確まで最長 5 日)。向き: でたらめ(seed 1〜20)/ 20 日の流れ / その逆
- B 両側の注文: P0 ± k x wv(k 0.5・1.0)に、指値(逆張り)か逆指値(順張り)を発表の足と次の足の間だけ置く。
  逆張りの出口は tp(P0 で利確、最長 24h)/ tp_stop / 2h / 24h、順張りは 2h / 24h
- C 跳ねた後の押し目: 発表の足で 0.5 x wv 以上動いたら、半分戻った値に動いた向きの指値(with)、または動いた先の 1/4 先に逆向きの
  指値(against)を 4 時間。出口 24h / 72h / stop_p0。200 日の平均の向きとそろうときだけの版も
- 対照: 同じ決まりを、発表の無い金曜の同じ時刻に当てる
- 約定は E050 と同じく不利な側に倒す。発表の足と次の足のスプレッドを 2 pip 広く見た版も回す
- 1 回の損益は 7 ペアの平均(ドルのペアは一緒に動くので、独立なのは発表の回数)。t はその平均 ÷ 標準誤差

```bash
python -m fxsim.research.event_nfp
python -m fxsim.research.event_nfp --extra-pips 2
```

## 判定
却下。
- 利用者の最初の案(片側・逆指値なし・跳ねたら利確・負けは落ち着いたら閉じる)は、向きを当てる情報が無い限りマイナスで、
  勝率の高さと引き換えに 1 回で口座を飛ばす損を抱える。「世間の情報で向きを決める」を AI にやらせると、過去の検証では
  未来が漏れる(E061)ので、測れるのはこの「でたらめな向き」までになる
- 両側の指値は発表の後に走る向きに刺さって負ける。鏡の順張りと押し目は向きは合っているが、t 1.3 以下で費用の見積もりも甘い
- 発表の無い金曜(対照)はどれもほぼ 0 かマイナスなので、発表に意味が無いわけではない(動きは大きい)が、取り方が無い

- 本物のエンジン(pair-eval)には通さない。研究の約定は、記録の最小スプレッドで甘めに見積もっていて、それでも全部の形がマイナスか t 1.3 以下。
  エンジンは費用を足す向きにしか働かないので、判定は変わらない。量を小さくする版も、1 取引の期待値の符号は量で変わらないので回さない
- 発表の種類を問わない版(跳ねた足の後に入る形)は E063 で 28 ペアに広げて測り、同じ結論だった
