# E040 デイトレードの頻繁な取引が、実口座でどれだけ削られるかをデモ口座で測る

- 種類: 実験 / 状態: 実施中(2026-11-12 開始)
- 実装: 動作ケース B056(基本検証の `scalping` v1、S013)、常駐の設定 `configs/trading/demo-usdjpy-b056.yaml`(magic 20261115)、
  集計 `fxsim/research/live_costs.py`
- 親: B031(スキャルピング 5 分足)、E037(デモ口座の実証実験)

## 問い
利用者の希望: 基本戦略のデイトレードをデモ口座で回し、頻繁な取引が実環境でどこまで酷いかを確かめたい。
シミュレーション(相場の DB の足、記録のスプレッド、OANDA の口座)が見積もる費用と、実口座で実際に払う費用
(スプレッド・注文を出してから約定までの滑り・逆指値と指値の約定の値段)はどれだけ違うか。

## 設計(回す前に決めた)
- 戦略: 基本検証のスキャルピング(5 分足、20 本 EMA の向きに直近 6 本の高安を抜けたら入る、利確・損切りとも 5 pip、
  24 時間)。USDJPY、1,000 通貨(0.01 ロット、OANDA の最小)
- 取引の時間: 始めは基本検証と同じ 7〜17 時 UTC(日本時間 16〜2 時)だったが、開始の日(2026-11-12)に利用者の判断で
  24 時間にした(`params: {start_hour: 0, end_hour: 24}`)。夜中とロールオーバーの広いスプレッドも測る
- 両方の向きに入る(swap_side_only を外す)。頻度を上げるため(受け取る向きだけだと半分になる)。±5 pip で数十分で
  決着するので、ロールオーバー(21〜22 時 UTC)をまたぐ建玉は少なく、スワップは小さい。戦略の評価(verify)
  には使わない動作ケース
- 回す前の見積もり(相場の DB の 5 分足 2025-07〜2026-11、OANDA の口座、`python -m fxsim sim B031 --market real_pair
  --market-params '{"source":{"path":"db:USDJPY/M5"}}' --broker oanda --engine '{"units":1000,"swap_side_only":false}'`):
  年 4,296 取引(1 日約 17)、勝率 45%、素の pip −268 / 年、スプレッドを引いて −1,988 pip / 年。1,000 通貨で 1.5 年 −3.05 万円
  (1 日あたり約 −80 円)。24 時間にすると(同じコマンドに `--params '{"start_hour":0,"end_hour":24}'`)、年 9,356 取引
  (1 日約 36)、勝率 42%、素の pip −844 / 年、スプレッドを引いて −8,575 / 年(1 取引 −0.92 pip、うちスプレッド約 0.83 pip)、
  1.5 年 −13.2 万円(1 日あたり約 −240 円)。コスト抜きでも優位性は無い(B031 は基本検証で不合格)ので、実験の目的は費用を測ることだけ
- 再生(7〜17 時 UTC の版、`python -m fxsim trade-replay configs/trading/demo-usdjpy-b056.yaml --faults none --start 2026-11-02 --end 2026-11-07`):
  5 日で新規 99(利確 53・損切り 46)、注文は全部成功、シミュレーションとの食い違いは起動直後の 1 本だけ
- 測り方: `python -m fxsim fetch-mt5 configs/market_data/oanda-demo-majors.yaml` で相場の DB を追いつかせてから
  `python -m fxsim.research.live_costs configs/trading/demo-usdjpy-b056.yaml --since 2026-11-12`。
  実口座の建玉(端末の約定の履歴)と、同じ期間のシミュレーションの取引を、向きと建てた時刻(6 分以内)で対にして比べる
  - 建値と決済の値段の差(pip、正が実口座に有利)、1 取引の pip の差、決済の理由(利確・損切り)が同じ割合
  - 注文を出したときの気配から約定までの滑り(常駐の記録 journal.jsonl)
  - 取引の数(1 日あたり)、勝率、損益(円)
- 当否: 1 取引の pip の差の平均が −0.2 pip より悪ければ、シミュレーションは実口座の費用を甘く見ている
  (シミュレーションの費用の 1.5 倍を超えるか。24 時間では 1 取引約 0.8 pip。時間帯ごとにも分けて見る)。最低 2 週間(約 200 取引)は回す
