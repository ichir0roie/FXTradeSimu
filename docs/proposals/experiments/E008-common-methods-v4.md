## 読み取れること
1. **E006 で勝っていた逆張り(RSI・ストキャス)と parabolic_sar は、v4 では全部負けた**(fair の総合の中央 +20〜26 万 → −21〜−37 万)。
   勝ちは市場モデルの穴(R008)と損切りの約定の偏り(E007)から来ていた。E006 の「市場モデルの穴に乗った勝ち」という判定どおり
2. E006 の結論 1〜4 は変わらない。勝つのは円安・金利差に乗ったもの(buy_and_hold・キャリー)だけで、回転の速い手法は費用で死に、
   賭け方は全部破綻する
3. **破綻の列で、賭け方の型の結末がはっきり見える**。fair でも 91〜100% のパターンが 10 年のうちに有効証拠金の 1 割を割る。
   E006 では全部「破綻 0」と表示されていた(E007)
4. london_breakout・heikin_ashi は E006 より負けが減った(−23 → −7 万、−35 → −19 万)。どちらも malicious 市場 v4 で
   5 分〜数十分の勢いが消えた影響(M006)。プラスにはならない

## 判定
手法の実装は E006 のまま採用。**単純な手法で、市場の穴に頼らずに安定して勝つものは無い**(E006 と同じ。穴に乗った勝ちが消えて、
より明確になった)。
