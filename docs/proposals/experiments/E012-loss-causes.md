# E012 全戦略の敗因と、共通する因子・回避策

- 種類: 実験(分析。新しく回していない) / 状態: 完了(2026-11-10)
- 材料: E011 の 44 本の検証(`docs/results/V-B0xx-20261110T*`、30 年・malicious ブローカー・1 万通貨・初期 100 万円)
- 親: E011、E007(費用の内訳)、E008(手法の一覧)
- 集計: 並べ替え(real_bootstrap、複数ペアは basket_bootstrap)10 本の平均。対照に方向でたらめ版・偽薬・ドリフト抜き・完全ランダム

## 問い
E011 で全部が負けた。何が負けさせたのか(信号に中身が無いのか、費用か、スワップか、賭け方か)を戦略ごとに分け、
共通する因子と、それを避ける手を整理する。避ける手のうち、このリポジトリで確かめられるものを次の案にする。

## 読み方
- 素の損益 / 取引: スワップと売買の費用を引く前の、1 取引あたりの pip。t は 10 パターンの t
- 方向でたらめ版: 同じ時刻に入って出るが、向きだけでたらめにした版の素の損益 / 取引。差が戦略の向きの情報
- 偽薬: 日ごとの値動きの符号を入れ替えた相場(日足の構造は消え、日中の作り方は残る)
- 費用 / 取引: スプレッド + スリッページ(malicious。不利な向きだけ、損切りは 2.5 倍)
- 素の損益(万)・スワップ(万): 30 年の合計の平均。破綻したパターンは途中で止まるので、その分小さく出る
- 破綻: 有効証拠金が初期の 10% を割ったパターンの割合 / そこまでの年数の中央値
- 注意: 複数ペアとリピートは 1 本の脚(一部決済)を 1 取引に数える。賭け方は量を変えるので pip と円の向きがずれる(B044)。
  B018 は取引 1 回、B034 はほぼ 0 回なので pip / 取引は出さない

## 2. 共通する因子

負けは 4 枚の壁で説明できる。下の壁ほど多くの戦略を止めている。

### 壁 0: 値動きの情報が無い(ほぼ全部)
- 賭け方を除く日中の 20 本(1 時間足以下と 4 時間足)で、素の損益 / 取引は −5.6〜+2.1 pip。費用(壁 1)を越えるものは無い
- 素の損益 / 取引が有意にマイナス(t ≤ −2)で、random_entry の −0.49 pip(見えない費用、壁 1)より悪いのが 11 本:
  B001・B011・B012・B021・B022・B025・B026・B028・B030・B031・B033。規則が相場と逆に働いている。
  逆にしても、大きさは B021・B022(4 時間足、−4.1・−5.6 pip)を除けば 0.2〜1.7 pip で費用を越えない。B021・B022 は偽薬では
  −1.3・+0.2 に縮むので、日足の値動きの構造ではない(原因は未解明)。B033 タートルは下の注
- 有意にプラスの日中の戦略(B002 +1.48・B020 +1.94・B029 +0.55)は、偽薬でもほぼ同じだけ残る。日足の値動きの構造ではなく、
  日中の足の作り方(実データの日足をつなぐ合成)から来ている疑いが強い。追う前に作り方を疑う(E006 の逆張り・R008 と同じ型)
- 日足で素の損益 / 取引がはっきりプラスなのは、時系列モメンタム(B007 +10.3 pip、t 1.8)と勾配ブースティング(B015 +23.3、t 2.1)。
  キャリー(B008)・リピート(B016)・買い持ち(B018)の素の損益は円安の分で、ドリフトを抜くと消えるか有意でなくなる(E011)
- 注: タートル(B033)は素の損益 / 取引 −95 pip で、どの相場でもマイナス(勝率 13%)。積み増した単位を 1 取引に数えている影響もあり、
  pip の大きさは他と比べられない

### 壁 1: 1 取引ごとの費用(日中の 29 本と賭け方を止める)
- malicious の費用は 1 取引 1.7〜2.9 pip(スプレッドとスリッページがほぼ半分ずつ)。ほかに、素の損益の中に見えない費用が
  約 0.5 pip ある: 中身の無い random_entry の素の損益が 0 ではなく −0.49 pip / 取引。ラストルック(客に有利な始値の約定を拒否)と
  ストップ狩りの分(1 取引あたりの拒否は日中で 0.2〜5 回、スキャルピングで 16 回、賭け方で 1〜33 回)
- 損益分岐の目安: 素の損益 / 取引が 約 3 pip を越えないと、どれだけ回しても負ける。日中の戦略(賭け方を除く)の素の損益は最大でも 2.1 pip
- 回数が効く: 1 万通貨で 3 pip = 300 円。年 100 回なら年 3 万円、30 年で 90 万円 = 初期資金のほぼ全部。
  年 110 回を超える戦略は、情報が無ければ 30 年以内に資金を費用で使い切る(1 時間足以下の 22 本中 19 本が、並べ替えの 80% 以上で破綻)

### 壁 2: 持っている間のスワップの上乗せ(日足・4 時間足の持ち続ける戦略を止める)
- malicious のスワップの上乗せは年率 1%。USDJPY 1 万通貨(約 110 万円分)なら年 1.1 万円 = 年 110 pip 相当を、向きに関係なく払う
- 建玉の時間が長い戦略(露出 0.5〜1.0)は 30 年で −10〜−36 万円。日足の時系列モメンタムでは 1 取引あたり約 4.4 pip 相当で、
  費用(2.6 pip)より重い
- 日足の戦略は壁 1 を越える(素の損益 10〜23 pip / 取引)のに、ここで止まる: B007(素の損益 +48 万 → スワップ −21 万)・
  B014(+28 万 → −36 万)・B015(+37 万 → −21 万。残り +11 万、t 1.07)
- 売りのリピート(B017)は円安の相場で売りを持ち続け、スワップ −73 万で 80% が破綻

### 壁 3: 量の増やし方(賭け方 9 本)
- 素の損益 / 取引は random_entry と同じ −0.4〜−0.7 pip(賭け方は期待値を変えない)
- 結果で量を変える型(マーチンゲール・ダランベール・ラブシェール・パーリーなど)は 0.3〜1.4 年で破綻。量が固定の bet でも、回転(年 1,700 回)の費用で 2.2 年。ケリーでも 10 年
- ナンピン・マーチンゲール(B044)は勝率 97%、素の損益 / 取引 +7.4 pip でも、円では −54 万。小さな勝ちを積んで、まれに大きく負ける

### 壁の外: 1 本の歴史と期間への依存
- 実データ 30 年でプラスでも、並べ替えた歴史で負けるもの: B004(実データ +37 万、並べ替え t −0.15)・B011(+41 万、中身はスワップ)
- 実データでも並べ替えでも勝つが、中身が円安とスワップのもの: B016・B018・B008
- 合成の相場では金利差を時刻どおりに当てるので、金利の高い通貨を持つ戦略が有利に見える(E011)

まとめ:
- 壁 1 と 3 は避け方が分かっている(回さない・費用の小さい口座・量を増やさない)。避けても、残るのは「負けない」まで
- 壁 2 は日足の戦略にとって一番重い。口座の選び方で大半が変わる
- 壁 0 が本題。値動きの過去だけを見る単純な規則には、費用を越える情報が無い。費用を越えそうなのは、日足以上で
  値動き以外の情報(複数ペアの相対・金利・物価)を使うものだけで、それも試した数を考えると偶然と区別できていない

## 判定
個々の戦略の作り込み(パラメータの調整)で直る負けではない。負けの大半は「情報が無いのに回す」「持っている間にスワップの上乗せを払う」
「負けた後に量を増やす」の 3 つの組み合わせで、どれも戦略の型で決まる。改善の余地があるのは、日足以上・低回転・費用の小さい口座の
組み合わせで、値動き以外の情報を使う戦略だけ。
