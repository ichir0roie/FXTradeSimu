# E067 米新規失業保険申請件数(毎週木曜)で、雇用統計と同じ形を測る

- 種類: 実験 / 状態: 完了(2026-11-13)。全部の形が不合格
- 実装: `fxsim/research/event_nfp.py --event claims`、日付の決まり `fxsim/calendar.py` の `claims_dates`。
  本物のエンジンは S053 の `event_one_side`(trigger = claims、v2)、動作ケース B090・B091
- 親: E062(米雇用統計)、E063(跳ねた足)

## 問い
E062 の形(片側・逆指値なし・利確・落ち着いたら閉じる、両側の注文、跳ねた後の押し目)は、雇用統計(16 年で 184 回)以外の
発表でも同じか。日付を記憶から並べると間違うので、決まりで作れる発表を選んだ: 新規失業保険申請件数は毎週木曜 8:30
ニューヨーク(木曜が連邦の祝日なら前の水曜)。16 年で 841 回あり、雇用統計の 4 倍以上の標本になる。

## 設計(回す前に決めた)
- 形と約定は E062 と全く同じ(A 片側・逆指値なし 48 通り、B 両側の注文 12 通り、C 跳ねた後の押し目 12 通り)
- 対照: 発表の無い火曜の同じ時刻(8:30 ニューヨーク)
- 確かめ: EURUSD の発表の足の幅の中央値 22.2 bp、対照 17.5 bp(雇用統計ほど大きくはないが、発表の足は荒れている)
- 本物のエンジン: B090(利確 0.5・落ち着いたら閉じる)・B091(利確 0.25・5 日まで待つ)、pair-eval(主要 10 ペア x 4 期間)

```bash
python -m fxsim.research.event_nfp --event claims
python -m fxsim.research.event_nfp --event claims --extra-pips 2
python -m fxsim pair-eval B090 B091 --broker oanda
```

## 判定
却下。片側・逆指値なし・跳ねたら利確・負けは落ち着いてから閉じる形は、雇用統計(E062・B085〜B087)、発表の種類を問わない跳ね
(E063・B088・B089)、新規失業保険申請件数(E067・B090・B091)のどれでも負ける。標本が 4 倍の失業保険で、負けははっきりした
(B090 は t −5.68、方向でたらめ版よりも悪い)。
