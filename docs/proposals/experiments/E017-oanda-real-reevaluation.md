# E017 仮想の悪意を外し、OANDA の口座の条件で全 45 本を実データで評価し直す

- 種類: 実験 / 状態: 完了(2026-11-11)。合格 0 本
- 実装: ブローカーのひな形 `oanda`(`fxsim/backtest/broker.py`)、`real_pair` v2(R012、1 分足のサーバーの時ごとのスプレッド)、
  `python -m fxsim pair-eval --all --broker oanda`(日足は `--daily-fill-hour 2` の版も)
- 親: E016(同じペア x 期間を、動作ケースのブローカー = 多くは malicious で回した)

## 問い
これまでの評価は、悪意あるブローカー(不利な向きだけの滑り・ストップ狩り・ラストルック・スプレッドとスワップの上乗せ)という
仮想の設定を多くの動作ケースに入れていた。実際に使う OANDA 証券の MT5 口座の条件だけにしたら、各戦略はどうなるか。

## 設計
E016 と同じペア x 期間(日足 50、1 時間足 40、5 分足 40、複数ペア 5 パターン)で、ブローカーだけを全部の動作ケースで `oanda` に差し替えた。
MT5 の口座のひな形(B045 の `jp_domestic`)はそのまま。

| 項目 | oanda | 根拠 |
|---|---|---|
| スプレッド | 上乗せなし。市場モデルが業者の記録を使う: 足ごとの記録(足の中の最小)と、同じ銘柄の 1 分足の「サーバーの時」ごとの平均の大きい方 | 相場の DB(OANDA のデモの足) |
| 滑り | 0.1 pip の正規。有利にも不利にも動き、利確の有利な窓は客に渡す | デモは成行が即約定・リクオートなし(E014) |
| ストップ狩り・ラストルック | なし | 仮想の悪意なので外す |
| スワップ | 金利差から、受け取る側は年 0.44%、払う側は年 1.10% を業者が引く(`swap_markup_pay` で両側を分けた) | 2026-11-11 の端末のスワップの点数と各国の短期金利の差から逆算した 10 ペアの平均 |
| ロスカット | 証拠金維持率 100%、ゼロカットなし、25 倍 | OANDA 証券の MT5 スタンダード |

### 1 分足で分かったスプレッドの形
サーバーの時(ロールオーバー = 0 時、日本時間の 6 時(夏)・7 時(冬))ごとの平均(2026-08〜11):

| | 0 時台 | 1 時台 | 2 時台 | 3〜21 時 | 22 時台 | 23 時台 |
|---|---:|---:|---:|---:|---:|---:|
| USDJPY | 7.6 | 1.9 | 0.5 | 0.4 | 0.5 | 1.1 |
| EURUSD | 約 5 | 約 2.5 | 0.5 | 0.5 | 0.5 | 0.9 |
| GBPJPY | 約 20 | 約 6 | 1.5 | 0.9〜1.0 | 1.0 | 1.7 |

ロールオーバーの 1 時間はまるごと広い(USDJPY は 0 時ちょうどから 6〜10 pip)。MT5 の日足はサーバーの 0 時に始まるので、
「日足が確定したら次の足の始値で約定」する日足の戦略は、毎回この幅を払う。今の常駐の B045 もサーバーの 0 時に判断している(E014)。
そこで日足の戦略は、約定を 2 時(スプレッドが平常に戻る)に遅らせた版も回した(`daily_fill_hour: 2`。値段は始値のまま、スプレッドだけ
2 時台の平均にした近似)。

```bash
python -m fxsim pair-eval --all --broker oanda
python -m fxsim pair-eval B004 B007 B008 B010 B016 B017 B018 B033 B034 B035 B045 --broker oanda --daily-fill-hour 2
```

## 判定
仮想の悪意を外し、OANDA の口座の条件と実データだけにしても、合格する戦略は無い。悪意は「負けの大きさ」を決めていたが、
「勝てるかどうか」は変えていなかった。勝ちに一番近いのはキャリー(B008)で、中身は金利差の受け取り。
運用で直ちに効く発見は、日足の約定をロールオーバーの 1 時間から外すこと(1 取引あたり 5〜7 pip の差)。

## 限界
- スプレッドの時ごとの平均は、1 分足の 3 か月(2026-08〜11)から作り、30 年の全部に下限として当てている(昔の記録の方が広い期間は記録が勝つ)
- 日足の約定を遅らせた版は、値段を始値のままにしてスプレッドだけ替えた近似
- スワップの業者の取り分は今の 1 時点の点数からの逆算。昔の取り分は分からない
- 円への換算は期間の最初の値で固定(R012)
