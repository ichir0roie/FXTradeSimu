# E010 複数通貨の手法: ブローカーごとの差と、試した数の補正

- 種類: 実験
- 状態: 実行済み
- 設定: `configs/basket_methods.yaml`(E010)、`configs/basket_demeaned.yaml`(E010b、ドリフトを抜いた並べ替え)
- 概要: `docs/results/E010-20261110T084347-103049/`(E010)、`docs/results/E010-20261110T084850-840fbd/`(E010b)
- 親: S032〜S037、E008(1 ペアの手法の一覧)

## 仮説
- 複数通貨の手法(順位・トレンド・勾配ブースティング)は、1 ペアの手法より回転が少ない(月 1 回の入れ替え)ので、
  ブローカーの悪意の効き方は主にスワップの上乗せになる
- 16 本の設定(手法 x パラメータ)の中で一番良いものを選んでも、並べ替えた別の歴史では平均並みになる(PBO ≈ 0.5)なら、
  選んだ一番の良さは選び方の運

## 設計
- 対円 7 ペア、30 年(データは 1999-01〜2026-11 の約 27.8 年)、fair / ecn / malicious
- 市場: basket_real 1 本、basket_bootstrap(250 日ブロック)8 本、basket_placebo 8 本、basket_random_walk 4 本
- 戦略: キャリー 3 本(1x1 / 2x2 / 3x3)、モメンタム 4 本(21 / 63 / 126 / 252-21 日)、バリュー 2 本(3 / 5 年)、
  トレンド 3 本(63 / 126 / 252 日)、勾配ブースティング 1 本、USDJPY の carry_trade・buy_and_hold・random_entry(日足)

## 測り方
```bash
python -m fxsim run configs/basket_methods.yaml
python -m fxsim overfit <run_key> --market basket_bootstrap --broker fair
python -m fxsim overfit <run_key> --market basket_real --broker fair
```
- ブローカーごとの損益の差と費用の内訳(report の「費用の内訳」)
- PBO(並べ替えの 8 本の平均)と、戦略ごとの Deflated Sharpe

## 判定
1. 回転が少ないので、ブローカーの差はほとんどスワップの上乗せで決まる。malicious は年率 1% を両側から取るので、
   建玉の総額 150 万円で 27.8 年に約 −42 万円。順位の手法・トレンドの素の損益(+0〜+90 万)の大部分がこれで消える
2. トレンド 63 日と勾配ブースティングは、ドリフトを抜いた並べ替えでも素の損益が残る(t 2.8・3.95)。
   実際の為替の数週間〜数か月のトレンドの塊を拾っている。偽薬(日ごとの符号でたらめ)と完全ランダムでは消えるので、
   作り方の癖ではない。トレンド 126・252 日は、ドリフトを抜くとほぼ 0 になる(長い窓は、この期間の上げ下げに乗っていた)
3. キャリーは、どの並べ替えでも素の損益がマイナスで、勝ちはスワップ。偽薬で大きく勝つ(t 7.3)のは、
   値下がりで埋め合わされない相場だから
4. PBO は 0.21〜0.31。選び方に少しは情報がある(モメンタムが一貫して悪い)が、Deflated Sharpe が 0.95 に届くものは無い。
   実データで一番の勾配ブースティング(年率シャープ 0.41)も、16 本試した中の一番としては偶然で説明がつく
5. PBO は 1 本の歴史では大きくばらつく(中身の無い 30 本でも 0.07〜0.65。`tests/test_overfit.py`)。並べ替えの 8 本で平均して読む
