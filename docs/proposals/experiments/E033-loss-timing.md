# E033 短期の基本のテクニカル手法は、いつ負けるのか(USDJPY の実データ、時間足ごとに 1 本)

- 種類: 実験(分析) / 状態: 完了(2026-11-11)。1 本の歴史での整理で、区分ごとの結論は候補
- 実装: `fxsim/research/loss_timing.py`(`python -m fxsim.research.loss_timing`)
- 親: E012(全戦略の敗因)、E021(費用を越える時間の長さ)、E023(局面の地図、日足)

## 問い
短期売買の基本のテクニカル手法について、

1. 勝つ確率(勝率)と負ける確率、勝ったときの利益率・負けたときの損失率はどれくらいか
2. 負けはどのタイミング(時間帯・曜日・ボラ・もみ合いか一方向か・流れの順逆・持つ長さ・決済の理由)に集まるか
3. 1 と 2 は時間足(1 分・5 分・15 分・1 時間・4 時間)でどう変わるか

を、USDJPY の実データ 1 本ずつで整理する。

## 仮説(回す前に書く)
- H1 勝率と損益比は手法の形で決まり、どれも費用を引くと期待値が 0 以下になる(E012・E021)。
  逆張り(RSI・ボリンジャー・ストキャス)は勝率が高く損益比が小さい、順張り(MA・MACD・ブレイクアウト・SAR など)は逆
- H2 足が短いほど、1 取引の値幅に対する費用(スプレッド + 滑り)の割合が大きく、負けの多くは「素の損益はプラスだが
  費用で負けに転じた取引」になる。1 分足・5 分足では素の期待値が 0 付近でも費用だけで大きく負ける
- H3 負けの集まる時間帯は、スプレッドが広がる早朝(日本時間 2〜7 時。NY の引けからオセアニア)と、方向が出る欧州・NY の寄り。
  逆張りは一方向(効率比 > 0.4)・流れに逆らう(逆行)局面で負け、順張りはもみ合い(効率比 < 0.2)で負ける
- H4 荒い局面(ATR が普段の 1.25 倍超)は、どの手法でも 1 回の負けが大きい

## 設計
- 相場: 相場の DB の USDJPY(OANDA の MT5、時刻は UTC)を real_pair(R012)でそのまま再生。
  約定を足の中まで見るため、時間足ごとに一番細かいデータを使う

  | 戦略の足 | 相場の DB の足 | 期間 |
  |---|---|---|
  | 1 分 | M1 | 2026-08-05〜2026-11-11(3 か月) |
  | 5 分・15 分 | M5 | 2025-07-09〜2026-11-11(16 か月) |
  | 1 時間・4 時間 | H1 | 2010-10-06〜2026-11-11(16 年) |

  参考に、1 時間・4 時間を 5 分足と同じ期間(2025-07-14〜2026-11-10)でも回し、足の違いと期間の違いを分ける
- 手法(既定のパラメータのまま、timeframe だけ変える): ma_cross(EMA 20/100)、macd_cross(12/26/9)、perfect_order、
  adx_trend、ichimoku、parabolic_sar、heikin_ashi、donchian_breakout(48/24)、rsi_reversion(30/70)、
  bollinger_reversion(±2σ)、stochastic_reversion(20/80)
- 帰無: 同じ時刻に入って出る方向でたらめ版(direction_null)を対で回す。同じ区分での期待値の差が、規則の向きの情報
- ブローカー: oanda(仮想の悪意なし。記録のスプレッド、往復 0.2 pip の滑り)、1 万通貨、スワップ込み。
  短期の手法の性質を見るため、スワップを受け取る向きだけの決まり(E022)は掛けない(掛けると USDJPY は買いだけになる)
- 数字の定義
  - 勝ち: 円の損益(スワップ・費用込み)> 0。利益率・損失率は建玉の額(1 万通貨 x 約定価格)に対する %
  - 素(pip): mid どうしの値幅(費用抜き)。費用 = スプレッド + 滑り
  - 費用負け: 素の損益 > 0 なのに費用を引いて負けた取引。負けのうちの割合
  - t: 週ごとの損益の合計で数える(同じ週の取引は独立でないので、取引単位の t は使わない)
- 局面の区分(入る判断をした確定足で数える。どれも因果的で、閾値は回す前に決めた)
  - 時間帯(日本時間、約定時刻): 東京朝 7〜10 時(仲値を含む)/ 東京 10〜15 時 / 欧州 15〜21 時 / NY 21〜翌 2 時 / 早朝 2〜7 時
  - 曜日(日本時間): 月曜 / 火〜木 / 金曜(土曜の早朝は金曜に数える)
  - ボラ: ATR(14) / その直前 500 本の ATR の中央値。静か < 0.8 / 中 / 荒い > 1.25
  - 一方向: 20 本の効率比(|20 本の動き| / 1 本ごとの動きの絶対値の和)。もみ合い < 0.2 / 中 / 一方向 > 0.4(E013 と同じ)
  - 流れ: 60 本の対数リターン / (20 本のボラ x √60) を建てた向きで見る。逆行 < −0.5 / 中立 / 順行 > +0.5(E023 と同じ)
  - 持つ長さ: 戦略の足で 3 本以下 / 4〜20 本 / 21 本以上
  - 決済の理由: signal(規則)/ reverse(ドテン)/ sl(損切り)/ その他
- 1 本の歴史なので、区分の数字は「この期間の USDJPY ではこうだった」以上のことは言わない。11 手法 x 5 足 x 7 切り口から拾うので、
  t 2〜3 は偶然でも出る

## 測り方
```bash
python -m fxsim.research.loss_timing
```
H1〜H4 を、手法 x 時間足の成績表と、切り口ごとの「負けの集まり方」(勝率、1 取引の期待値、方向でたらめ版との差、
負け額の割合 / 取引の割合)で確かめる。

### 素の優位性(1 時間・4 時間、16 年)
- 順張りの素の損益は +1.4 / +3.5 pip(方向でたらめ版の期待値 −1.2 / +1.0)。ただし週の t が 2 を越えたのは 1 時間足のパーフェクトオーダー
  (+2.3)だけで、11 手法 x 5 足から拾った値。5 分足と同じ期間に切ると、4 時間の順張りは −2.2 pip になる
- 逆張り 3 本の 1 時間足は、16 年で素の損益もマイナス(−1.4 pip)。週の t は RSI −3.2・ボリンジャー −4.0・ストキャス −4.4。
  USDJPY の 1 時間足では、逆張りの規則は相場と逆に働く(E012 の B025・B026 と同じ)

### mid の作り方による注意
相場の DB の価格は bid で、mid = bid + スプレッド / 2(`fxsim/data/real.py`)。ロールオーバーでスプレッドが 0.4 → 8 pip に開くと mid が
約 4 pip 跳ねるので、1 分足の順張りの信号の一部(1 分足の MA クロスは取引の 59% が早朝)はこの作り方から出ている可能性がある。
費用(記録のスプレッド)は本物。bid のチャートで動く EA は、同じ時刻に違う信号を出しうる。

## 判定
- H1(手法の形で勝率と損益比が決まり、費用を引くとほぼ 0 以下): 支持。順張り 22〜35% / 損益比 1.5〜2.1、逆張り 46〜54% / 0.76〜0.82。
  損益分岐の勝率に届くのは順張りの 1 時間・4 時間だけで、それも素の優位性は有意でない
- H2(短い足ほど費用が負けを作る): 支持。ただし「素はプラスなのに費用で負けた取引」は負けの 1〜4% しかない。
  費用は 1 回ごとの勝ち負けを入れ替えるのではなく、勝ちを少し小さく、負けを少し大きくして期待値を削る
- H3(早朝と欧州・NY の寄りに負けが集まる。逆張りは一方向・逆行で、順張りはもみ合いで負ける): 一部支持。
  早朝は支持(原因はロールオーバーのスプレッド)。欧州・NY の寄りには集まらない。逆張りの一方向は支持。順張りのもみ合いは不支持
  (一方向での出遅れの方が負けが集まる)
- H4(荒い局面は 1 回の負けが大きい): 支持(1.1〜1.4 倍)
- 1 本の歴史(USDJPY、1 分は 3 か月、5 分・15 分は 16 か月)なので、区分の数字は候補。足の違いと期間の違いは、同じ期間での回し直しで
  順張り 4 時間が +2.3 → −2.2 pip に変わる程度には混ざっている
