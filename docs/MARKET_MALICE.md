# 市場の悪意

「悪意」= 個々の参加者が負けやすい方向へ、相場とブローカーが動くこと。
ただし、悪意が決め打ちだと逆張り(または順張り)で簡単に稼げてしまう。それは悪意ではなく、ただの癖。
このリポジトリでの目標は次の 3 つを同時に満たすこと:

1. **現実らしい**: 実際の為替の統計的性質(裾の厚さ、ボラの塊、ほぼゼロの自己相関、日足の分散比 ≈ 1)を保つ
2. **悪用されにくい**: どの単純な規則にも、安定した素の優位性(コスト抜きのシャープ)が無い
3. **痛い**: コスト・スプレッドの広がり・窓・ストップ狩りで、実際の損益は素の損益より確実に悪くなる

## 仕組みの一覧

### 市場側(`fxsim/markets/components/`)

| 部品 | 何をするか | 誰が痛いか | 主なパラメータ |
|---|---|---|---|
| `session` | 時間帯でボラが変わる(東京は静か、ロンドン・NY の重なりで荒れる) | 時間帯を無視した損切り幅 | profile |
| `stoch_vol` | 荒れた相場はしばらく荒れ続ける(45 分・1 日・15 日の 3 つの時間スケール) | 固定幅の損切り | halflives_min, stds |
| `news` | 指標(雇用統計 + ランダム)。ジャンプ、直後のボラ急騰、**一度逆に振ってから本命へ(whipsaw)** | 両方向の逆指値 | whipsaw_prob, nfp_pips |
| `regime` | レンジ・上昇・下降・荒れ相場が予告なく入れ替わる | 局面を決め打ちした規則 | states, transitions |
| `fat_tails` | ショックが t 分布 | 正規分布を前提にした資金管理 | df |
| `weekend_gap` | 週明けの窓 | 週をまたぐ逆指値(窓で滑る) | gap_pips |
| `range_reversion` | レンジ局面では開始値へ引き戻す | ブレイクアウト | halflife_hours |
| `crowd_squeeze` | **群衆の構成 w**(+1 順張り勢 / −1 逆張り勢、外からは見えない、数日〜数週で入れ替わる)の逆へ価格を押す | その時の多数派 | strength, mix_halflife_days |
| `false_breakout` | レンジを抜けたとき、ダマシ(押し戻し)か本物(走り)か。順張り勢が多いほどダマシ、逆張り勢が多いほど走る | ブレイクアウト勢と逆張り勢の両方 | prob_range/trend/other, follow_prob, crowd_gain |
| `stop_hunt` | キリ番・直近高安値へのヒゲ。結末は戻り(+ 逆へずれる)か連鎖(突き抜けたまま走る)。これも w で決まる | 損切りを置く全員、ヒゲに飛び乗る人、ヒゲを逆張りする人 | prob, revert_prob, crowd_gain |
| `spread`(Dynamic) | ロールオーバー・指標・ストップ狩り・週明けでスプレッドが広がる。広がるだけで bid/ask 側の逆指値が刺さる | 損切りを近くに置く人 | profile, news_mult, hunt_mult |

中心にある考え方は **「相場は、いま多数派の群衆が一番痛がる方へ動く」**。
`crowd_squeeze` が群衆の構成 w を `ctx.meta["crowd_mix"]` に残し、`false_breakout` と `stop_hunt` がそれを読んで結末を決める。
w は直接見えないので、同じ形(抜け・ヒゲ)でも結末が時期によって逆になる。
w を推定できる戦略(最近どちらの型が負けているかを見る、など)は、正当な研究対象として残している。

### ブローカー側(`fxsim/backtest/broker.py`、`malicious` プリセット)

| 仕組み | 内容 |
|---|---|
| 不利なスリッページだけ | `adverse_only`、その足の平均スプレッドに比例して大きくなる。逆指値は 2.5 倍 |
| 有利な窓は渡さない | 利確水準を窓で飛び越えても、利確価格で約定(`positive_slippage=False`) |
| あなたのストップを狩る | 逆指値まで `hunt_pips` 以内に来た足で、確率 `hunt_prob` で刺す |
| スワップの上乗せ | 買いの受け取りは少なく、売りの支払いは多く |

## 測り方(`fxsim/markets/evaluation.py`)

現実らしさ(目安の範囲は USDJPY を念頭に置いた概算で、厳密な実測値ではない):

| 指標 | 目安 | 意味 |
|---|---|---|
| annual_vol | 6–13% | 年率ボラ |
| kurt_h1 / kurt_d1 | 3–30 / 0.5–10 | 裾の厚さ(日足の方が正規に近い = 集計による正規化) |
| acf1_h1 | −0.05–0.03 | リターンの自己相関はほぼゼロ |
| acf_abs_h1_lag1 / lag24 | 0.15–0.55 / 0.08–0.5 | ボラの塊 |
| vr_h1_d1 | 0.80–1.15 | 日足と 1 時間足の分散比。1 からずれると、日足で順張り/逆張りの癖がある |
| daily_range_pct | 0.4–1.1% | 日足の平均値幅 |
| spread_median_pips / p99 | 0.2–0.6 / 1.5–15 | スプレッド |

悪意の量(目標なし、random_walk と比べて読む): `false_breakout_rate`、`wick_rejection_rate`、`events_per_day_*`。
悪用されにくさ: 戦略パネルの素のシャープ(CLAUDE.md の「物差し」)。

## 調整の記録

- v1 で最初に組んだとき、ダマシが常に戻るだけだったので日足の分散比が 0.74 まで下がり、逆張りが年 +1,600 pip 稼げた。
  → 「抜けて走る」を混ぜ、ストップ狩りにも「連鎖」の結末を足し、どちらになるかを群衆の構成 w で決めるようにした
- `range_reversion` の半減期 16 時間は、悪意の部品が無くても逆張りに素のシャープ +1.1 を与えていた(stylized)。
  malicious では群衆の逆突きで相殺されるが、stylized 単体ではまだ逆張り有利。→ 次の課題(M004)
- malicious v1 の既定値は 3 年 x 6 パターンで、素のシャープの絶対値の最大が 0.63(donchian_breakout +0.63、
  bollinger_reversion +0.61)。単純な規則にまだ少し穴がある。
- E001(10 年 x 8 パターン)では、ブレイクアウトが malicious 市場で 8 本中 7 本プラス(fair で中央値 +109 万円)。
  短い期間では見えなかった順張りの穴。→ 次の課題(M004、docs/proposals/markets/M003-malicious.md)
